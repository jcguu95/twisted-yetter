* 0. 文件地位

這份文件只依賴已獨立釘死的：

1. premodular fusion category \(\mathcal C\) 與 character
   \(\eta:\mathrm{Id}_{\mathcal C}\Rightarrow\mathrm{Id}_{\mathcal C}\)；
2. =SpecialKirbyDiagram=；
3. \(H_2^{\mathrm{Kirby}}(D)=\ker\partial_2/\operatorname{im}\partial_3\)；
4. typed ribbon graphical calculus；
5. Tham thesis Definition 5.11，thesis page 52／PDF page 58。

它不讀 repo 既有 evaluator、Sage、bridge 或 numerical artifacts。

舊版獨立 evaluator 自己重複建立的 =IntegralHandleChain= 與
=SpecialKirbyPresentationSemantics= 已刪除。現在 evaluator 只能使用同一份
=SpecialKirbyDiagram= 與 =KirbyH₂=。

* 1. 真正輸入與 Auxiliary Choices

公開 diagram-level 數學輸入是：

\[
  (\mathcal C,\eta),\qquad
  (D,\alpha),\qquad
  \alpha\in H_2^{\mathrm{Kirby}}(D).
\]

實際展開公式時暫時選：

1. cycle representative \(a\in\ker\partial_2\)，且 \([a]=\alpha\)；
2. 每一條 handle orientation line 的 generator；
3. 把 \(C_2\) element 解成逐 ordinary-handle integer coordinates 的 map；
4. 與上述 generators 相容的 dotted-puncture directions。

這些都不是公開 invariant 的 inputs。最後必須證明換任何一項都不改變數值。

* 2. Character Exponents

選定 chart 後：

\[
  a=\sum_{j=1}^{h_2}a_j e_j,
  \qquad a_j\in\mathbb Z.
\]

ordinary component \(j\) 上的 character coupon 是：

\[
  \eta_{\ell_j}^{a_j}.
\]

正 exponent 使用 \(\eta\)，負 exponent 使用 \(\eta^{-1}\)，零 exponent 是
identity。

這裡沒有 \(H_2=\mathbb Z\)，也沒有「整張 diagram 只有一個 exponent」。

* 3. Quantum Dimension 與 \(D\)

Quantum dimension不再是任意輸入的 scalar table。

對 simple object \(X_s\)，先在 typed graphical calculus 裡做標準 closed
pivotal loop，然後取它在

\[
  \operatorname{End}(\mathbf1)\cong K
\]

下的 scalar：

\[
  d_s=\operatorname{ev}_{\mathcal C}(\bigcirc_{X_s}).
\]

再定義：

\[
  D_{\mathcal C}
  =
  \sum_{s\in\operatorname{Irr}(\mathcal C)}d_s^2.
\]

這是 Tham 的 \(D\)，不是它的平方根。Normalization需要明列
\(D_{\mathcal C}\ne0\)。

* 4. Ordinary Components

對每個 ordinary framed \(2\)-handle component \(j\)，有限求和：

\[
  \ell_j\in\operatorname{Irr}(\mathcal C).
\]

該 component：

- label 是 simple object \(X_{\ell_j}\)；
- scalar weight 是 \(d_{\ell_j}\)；
- coupon 是 \(\eta_{X_{\ell_j}}^{a_j}\)；
- framing由原 =SpecialKirbyDiagram= 的 framed knot保留。

所有 ordinary labels 的總 weight：

\[
  \prod_{j=1}^{h_2}d_{\ell_j}.
\]

* 5. Dotted Components

對 dotted component \(i\)，使用它已選定的 spanning disk 與完整 puncture
list。依暫時 puncture directions，形成：

\[
  V_i
  =
  X_{\ell_{j_1}}^{\varepsilon_1}
  \otimes\cdots\otimes
  X_{\ell_{j_m}}^{\varepsilon_m}.
\]

在 cut 上插入：

\[
  P_{\mathbf1,V_i}
  =
  \sum_{\mu}
    q_\mu p_\mu,
\]

只保留 tensor-unit summand。

明確禁止：

- dotted component進入 ordinary simple-label sum；
- dotted component被染成 ordinary Kirby colour；
- 使用 transparent-sector projector；
- 使用 modular killing。

* 6. Topology-to-Graph Translation

對固定的 labels、character coupons與unit projectors，必須建造一張：

\[
  \Gamma(D,\ell,a):
  \varnothing\longrightarrow\varnothing
\]

的 typed closed ribbon diagram。

這一步只做 literal translation：

- 每條 ordinary framed component出現一次；
- 每個 character coupon出現在對應 ordinary component；
- 每個 dotted component不再作為 ordinary circle出現；
- 每張 chosen dotted disk切一次；
- 每個 cut只插入 \(P_{\mathbf1}\)；
- exterior crossings、cups、caps、twists及一般 morphism coupons原樣保留。

這個 translation boundary不能回傳 scalar，也不能宣稱 Kirby invariance。

* 7. Closed Graph Evaluation

建好的 \(\Gamma(D,\ell,a)\) 只能經過：

\[
  \text{typed ribbon syntax}
  \longrightarrow
  \operatorname{End}_{\mathcal C}(\mathbf1)
  \longrightarrow K.
\]

不存在任意的

\[
  \text{expanded term}\longrightarrow K
\]

黑箱。

* 8. Raw Sum

\[
 \operatorname{TY}^{\mathrm{raw}}_{\mathcal C,\eta}(D,a)
 =
 \sum_{\ell:\{1,\ldots,h_2\}\to\operatorname{Irr}(\mathcal C)}
 \left(
   \prod_{j=1}^{h_2}d_{\ell_j}
 \right)
 \operatorname{ev}_{\mathcal C}
 \bigl(\Gamma(D,\ell,a)\bigr).
\]

Denominator只有 ordinary \(2\)-handles。

* 9. Tham Normalization

用 dual handle decomposition讀 primal special Kirby diagram：

- 唯一 primal \(4\)-handle變成 dual index \(0\)，貢獻 \(D\)；
- 每個 primal \(3\)-handle變成 dual index \(1\)，貢獻 \(D^{-1}\)。

所以：

\[
 N_{\mathcal C}(D)
 =
 D_{\mathcal C}^{1-h_3}
 =
 \frac{D_{\mathcal C}}
 {D_{\mathcal C}^{h_3}}.
\]

Cycle-level formula：

\[
 \operatorname{TY}_{\mathcal C,\eta}(D,a)
 =
 D_{\mathcal C}^{1-h_3}
 \operatorname{TY}^{\mathrm{raw}}_{\mathcal C,\eta}(D,a).
\]

* 10. 下降到 \((D,\alpha)\)

上述 formula 暫時依賴 auxiliary choice。真正 diagram-level evaluator存在前，
必須證明：

\[
 \operatorname{TY}(D,a;\text{chart,directions})
 =
 \operatorname{TY}(D,b;\text{chart',directions'})
\]

只要：

\[
 [a]=[b]=\alpha.
\]

這一條同時包含：

- cycle representative independence；
- orientation-generator independence；
- coordinate-extraction independence；
- compatible puncture-direction independence。

完成後才得到：

\[
 \operatorname{TY}_{\mathcal C,\eta}(D,\alpha)\in K.
\]
