\section{Homologically Twisted Crane--Yetter Theory}
\label{sec:evaluator}
\label{sec:twisted-evaluator}

We define the homologically twisted evaluator directly.  Framed components
are summed over simple labels, dotted components insert the tensor-unit
projector, and a handle cocycle supplies the exponent of one character coupon
on each framed component.  The identity character recovers the established
Crane--Yetter handle formula.  We then prove representative independence and
marked Kirby--Cerf invariance for a general character, after which marked
Kirby--Cerf completeness descends the presentation-level value to an
\(H_2\)-marked 4-manifold.
