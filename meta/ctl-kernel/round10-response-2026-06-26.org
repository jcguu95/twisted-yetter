* What Changed

** Revision validation 分相

原本 =validate_revision= 同時做：

- Revision envelope checks；
- payload profile dispatch；
- supported profile payload validation；
- unsupported profile classification。

現在拆成：

- =validate_revision_envelope=
- =validate_revision_payload=
- =validate_revision=

因此 batch / transition path 可以先檢查 Revision envelope，累積 unsupported payload
profile，再繼續做 deterministic contextual checks。

** Batch common 先檢查 shape

=validate_batch_common= 現在先檢查：

- required batch keys；
- =parent_root= 型別；
- =recorded_revisions= shape；
- =principal_claim= / =submitted_by= / =admitted_at=；
- =binding_ops= schema；
- =evidence= schema。

之後才 resolve recorded revisions，並且遇到 unsupported recorded payload profile 時先記錄，
不立刻 return =UnsupportedProfile=。

** Genesis / transition 延後 unsupported classification

=derive_genesis= 與 =validate_transition= 現在會先完成可判定的 protocol invalidity：

- transition =parent_root= mismatch / missing；
- genesis =parent_root != null=；
- binding.set target not recorded；
- evidence CID membership；
- binding logical mismatch；
- parent membership checks。

只有這些 deterministic checks 都沒有產生 =InvalidHistory= 時，才回報 accumulated
=UnsupportedProfile=。
