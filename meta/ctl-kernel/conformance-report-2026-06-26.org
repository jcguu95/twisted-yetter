* Review Request

請下一輪 review 優先找：

- spec 和 reference 不一致；
- 同一 canonical bytes 產生不同 CID/root；
- validator 對支援範圍內的同一 history 分歧；
- 未授權 authority path；
- history/root replay forgery；
- legal bounded input 造成不受控資源消耗。

請不要再以 v0.1.1 blocker 形式要求：

- richer role ontology；
- signatures；
- remote log；
- UI；
- Chronicle full compatibility；
- additional domain-specific object types。

這些可進 =v0.1.2 backlog=。
