* 狀態

這個目錄是本 repo 的 object-first lab note / governance kernel 原型，不是 twisted Yetter 數學計算本身。

目前目標不是再擴寫 spec，而是把 CTL Kernel v0.1.1 的核心規則變成可重跑的 conformance evidence：

- canonical encoding
- object CID generation
- genesis derivation
- ordinary transition
- mandatory governance evaluator
- RoleBinding escalation / slot hijack regression tests
- root-chain replay
- UnsupportedProfile / InvalidHistory result aggregation fixtures
- mutation tests for CID tampering, replay forgery, evidence retargeting, and policy fast-forward

* Freeze Gate

v0.1.1 experimental freeze 之前，只讓以下類型阻擋：

** P0

- 未授權 principal 可以改變 canonical state。
- 同一 canonical input 可以產生不同 CID/root。
- 歷史可以被接受但無法由 parent + batch 重建。
- candidate policy 可以批准自己的 introduction。
- 不同合規 validator 對支援範圍內的同一 history 一個判 =Valid=，一個判 =InvalidHistory=。

** P1

- 可以破壞既有 authority assignment。
- 可以把未 recorded object 變成 active。
- evidence 可以被錯誤重用到另一個 operation。
- 合法且符合 limits 的 input 可造成不受控計算。
- crash-safe publish 可能讓 =refs/main= 指向不完整 state。

** 不阻擋 v0.1.1

- 更漂亮的角色 ontology。
- 多 parent root。
- signatures。
- encrypted compartments。
- remote append-only log。
- 更豐富的 selector。
- UI。
- 完整 Chronicle compatibility。

這些若重要，進 =v0.1.2 backlog=。
