* Caveats

這個 freeze 保留以下 caveat：

- 沒有 cryptographic actor authentication。
- 沒有 confidential compartments。
- 沒有 agent read capability enforcement。
- 沒有 sandbox / tool-call mediation。
- 沒有 raw filesystem crash recovery / fsync / rollback detection。
- 沒有 remote append-only anchoring。
- 沒有 full Chronicle compatibility。
- =agent/run-receipt/1= 只是 weak structural predicate。

=agent/run-receipt/1= 目前只證明 evidence CID 指向一個 structurally valid minimal
run-receipt Revision；它不證明 run success、fresh context、independent review、
target-specific review 或 reproduction。

* Post-Freeze Routing

Freeze 後變更路由如下：

- P0/P1 conformance 或 authority bug：v0.1.1 patch release。
- stronger evidence semantics：v0.1.2+。
- signatures / cryptographic actor authentication：v0.1.2+。
- raw local-store durability：v0.1.2+。
- capability runtime / sandbox mediation：v0.1.2+。
- multi-parent roots：v0.1.2+ 或更晚。
- richer research/company/software profiles：profile layer，不回頭修改 kernel core。

* Immediate Dogfood Target

建議第一個低風險 dogfood 目標是 CTL Kernel / ResearchCTL 自己的設計文件，而不是 twisted
Yetter 數學主線或高價值研究記憶。
