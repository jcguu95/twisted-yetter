* Implementation Change

=validate_batch_common= 現在回傳三個 accumulator：

#+begin_example
recorded
unsupported_profiles
unsupported_evidence_basis
#+end_example

所有 evidence entry 仍先做 deterministic shape checks：

- target shape；
- basis id grammar；
- cid shape；
- target membership。

若 basis id well-formed 但不在 =SUPPORTED_EVIDENCE_BASIS=，會加入
=unsupported_evidence_basis=。Genesis 和 ordinary transition 都在 deterministic invalidity checks
後才分類此 accumulator，以保持：

#+begin_example
InvalidHistory > UnsupportedProfile > Valid
#+end_example

因此 genesis non-empty evidence 仍是 =InvalidHistory=，即使 evidence basis unsupported。
