* Implementation Change

** Unsupported evidence 不再全域 short-circuit

之前 transition path 只要在 batch evidence 中看到 unsupported basis，就會先回
=UnsupportedProfile=。

這是不對的，因為某個 evidence entry 可能完全不被 matching policy rule 使用；它不應遮蔽
policy denial 或 child liveness failure。

本輪移除 transition-level global unsupported-evidence check。Unsupported evidence basis
現在只會在 supported policy evaluation 中，當 matching rule 的 required basis 本身 unsupported
時，透過 =policy_allows= 回報。

** Unsupported recorded / active profiles 延後到 child checks 之後

Recorded Revision 的 unsupported payload profile 仍會被累積，但不會在：

- request derivation；
- deterministic policy denial；
- child binding construction；
- future-policy-update liveness；

之前 short-circuit。

Active bindings 也改成先檢查 Revision envelope；若 active target payload profile unsupported，
先累積，等 deterministic child-state checks 完成後才回 =UnsupportedProfile=。
