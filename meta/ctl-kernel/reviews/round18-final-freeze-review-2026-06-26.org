* Remaining Caveats for Experimental Freeze

These should not block v0.1.1 experimental freeze, but must be stated clearly.

1. This is not a production local-store implementation. The in-memory reference store does not fully model byte-level filesystem ingestion, locking, fsync, crash recovery, or rollback detection.

2. This is not a security boundary for agent execution. v0.1.1 governs canonical admission state; it does not enforce confidentiality, sandbox reads, prompt isolation, model/tool capability issuance, or cryptographic actor authentication.

3. =agent/run-receipt/1= is a minimal structural profile only. Stronger evidence predicates should be v0.1.2+ work.

4. =reference/ctl_recompute.py= is intentionally small and separately written, but still Python. A later conformance milestone should add a second-language recomputation of canonical bytes, object CIDs, and root CIDs.

5. The fuzz pass was lightweight. A later robustness milestone should add property-based generation for malformed JSON, raw-byte canonicalization, and random transition graphs.
