* Fixed Issue

Round 17 指出的問題是：=AdmissionBatch.evidence[].target= 在欄位型別確認之前做 set
membership 檢查，因此 malformed JSON value 會逃成 Python host exception。

這次修掉的四個 regression cases：

- =target.kind = "recorded_revision"= 且 =target.cid = []=
- =target.kind = "recorded_revision"= 且 =target.cid = {}=
- =target.kind = "binding_op"= 且 =target.logical_id = []=
- =target.kind = "binding_op"= 且 =target.logical_id = {}=

修正後，上述 cases 都回：

#+begin_example
InvalidHistory
#+end_example

而不是：

#+begin_example
host:TypeError
#+end_example

* Implementation Note

在 =reference/ctl_ref.py= 的 =validate_batch_common= 中，membership check 之前先做 type /
grammar validation：

#+begin_example
recorded_revision target:
  die_unless(is_cid(target["cid"]), "bad evidence target cid")

binding_op target:
  die_unless(is_id(target["logical_id"]), "bad evidence target logical_id")
#+end_example

這保持既有 result lattice：

#+begin_example

#+end_example

Malformed protocol input 不應逃成 host-language exception。
