* Implementation Change

** Exact integer check

=PolicySet.payload.version= 現在必須滿足：

#+begin_src python
type(version) is int and version == 1
#+end_src

這避免 Python =True == 1= 的陷阱。

** Scalar sorting helper hardening

=unique_sorted_scalars= 現在會先確認每個元素都是 string，才呼叫 =sort_scalars=。Malformed array
entries 因此會回 =InvalidHistory=，不會從 =.encode()= 冒出 =AttributeError=。

** Binding op kind type check

=binding_op.op= 現在先確認是 string，再做 membership check：

#+begin_example
set | remove
#+end_example

因此 unhashable malformed values 會回 =InvalidHistory=，不會冒出 =TypeError=。
