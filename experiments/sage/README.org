* Purpose

=su2_2_braid_oracle.sage.py= 是目前的 exact SU(2)_2 braid-closure stress-test
oracle。它的用途是讓我們快速把 oriented link 寫成 braid closure，然後計算：

- fixed simple-label =SU(2)_2= framed RT link value；
- 每個 component 塗上 =Omega_a= 之後的 twisted Kirby-color expansion；
- sector amplitudes，方便之後做 finite Fourier / basis-change checks。

這不是 final local-piece evaluator。也就是說，它還不是把 arbitrary planar diagram
展開成 =ev=、=coev=、=R=、=F= 的正式 evaluator。它目前依賴 Sage 的 Jones
polynomial 來處理 =sigma= colored sublink。

* Payload Shape

#+begin_src json
{
  "n_strands": 2,
  "braid_word": [1, 1, 1],
  "framings": [0],
  "omega_labels": [1]
}
#+end_src

注意：

- braid generator 是 1-based；=+k= 表示 Sage 的 positive =sigma_k=。
- =framings= 與 =omega_labels= 是依照 closure components 排序，不是依照 strands 排序。
- components 依照 closure cycle 中最小的 original strand number 排序。
- output 會附 =components_0_based_strands= 與 =linking_matrix= 方便檢查。

* Current Trust Boundary

狀態標籤：=computed evidence / experimental oracle / not final evaluator=

已通過 self-test 的控制案例：

- =CP^2= 與 =CPbar^2= 單 unknot =Omega_0/Omega_1=；
- positive Hopf fixed labels =(1,2)= 與 =(1,1)=；
- =CP^2 # CP^2=、=CP^2 # CPbar^2=、=S^2 x S^2= 的 toy handle-slide values；
- right trefoil =Omega_0= 得到 =0=、=Omega_1= 得到 =4=。

第一批 stress suite 另保存：

- right trefoil positive / negative Markov stabilization；
- figure-eight braid conjugation，含 =0= framing 與 =+1= framing；
- trefoil split union unknot 的 multiplicativity。

自動 stress suite 另保存：

- 48 個 deterministic one-component small braid closures；
- 552 個 Markov / conjugation move checks；
- 2760 個 exact sector comparisons，包含 =Omega_0/Omega_1= 與 fixed labels =0,1,2=；
- scope 明確排除 multi-component =Omega= label permutation。

第一批 handle-slide toy suite 另保存：

- unknotted two-component slides：=CP^2#CP^2=、=CP^2#CPbar=、=S^2 x S^2=；
- right trefoil slid over a split =+1=-framed unknot；
- right trefoil slid over two split =+1=-framed unknots；
- generated 2-strand knot family slid over 1, 2, or 3 split =+1=-framed unknots；
- true connected-sum band slide：right trefoil slid over right trefoil；
- 帶既有 linking 的 true band slide；
- mixed slide-over framings =-1= 與 =+1= 的 true band slide，並檢查
  slide 後 off-diagonal linking term =l+f_2=；
- component-order permutation checks：component order 改變時，=Omega= labels 與
  framings 必須一起 permute；其中包含 hand-written swaps，以及 3-component /
  4-component pure-link diagrams 對所有 non-identity permutations 的 conjugation
  pressure tests；
- 每個 comparison 同時檢查 before value、after value、以及既有 lab note 的 expected value；
- 若任一值不一致，script 會以非零狀態停止。

尚未涵蓋：

- dotted / special link；
- 1-handle / 3-handle normalization；
- full Kirby diagram parser；
- arbitrary planar diagram 到 local tensor network 的轉換；
- arbitrary true band-sum constructor；目前只涵蓋幾個手寫但機械驗證的 true band
  slide toys，尤其 =|f_2|>1= 的 mixed framing 仍需要 framed push-off / cabling
  constructor；
- 對 twisted formula 本身的 theorem-level proof。

* MTC Candidate Data Boundary

=mtc_candidate_data.sage.py= 目前只做 category-side exact certificate：

- =SU(2)_6=：=U(C)=Z/2=，degree =j mod 2=。
- =Vec_{Z/3}^q=：=U(C)=Z/3=，=q(x)=zeta_3^{x^2}=，並附 pointed
  linking-matrix handle-slide controls。
- =SU(3)_2=：第一個 non-pointed =Z/3= candidate，degree =a+2b mod 3=。

它會記錄 fusion rules、quantum dimensions、twists、Hopf controls、=Omega_a=
coefficients、以及小型 algebraic controls。它不是 arbitrary colored link evaluator；
離開 pointed categories 後，fixed-label link evaluation 仍需要 explicit
=F/R=-symbol gauge 或 colored-Jones / fusion-space trace backend。

=vec_z3_pointed_stress.sage.py= 則利用 pointed category 的特性，直接把 framed
link evaluation 化成 linking matrix Gauss sum，測 =Q'=B^TQB= 與
=a'=B^Ta mod 3= 的 Kirby basis-change invariance。

=su2_6_modular_supported.sage.py= 完成 =SU(2)_6= 路線的前兩步：

- exact modular-data controls：=S^2=、fusion dimension algebra、=U(C)=Z/2=
  degree、=Omega_a= coefficient checks、simple-current character、以及
  =Omega_a= Hopf projector identities；
- modular-data-only supported evaluator：只支援 split union of framed unknots
  與 positive Hopf pairs，並明確拒絕 arbitrary linking matrix、trefoil、
  Borromean、Hopf-star、以及任何需要 explicit =F/R=-symbol traces 的 diagram。

這個檔案不是 =SU(2)_6= arbitrary link evaluator，也還沒有做 Kirby slide
invariance。下一步若要測真正 non-pointed Kirby moves，必須先加入
=F/R=-symbol 或其他等價的 colored link backend。

=su2_6_kirby_slide_stress.sage.py= 補上 =SU(2)_6= 的非平凡 Kirby-slide stress
suite。它支援的 move class 是：

- 一個 nontrivial knot component 以 one-component braid closure 表示；
- fixed-label knot value 用 Sage reduced colored Jones polynomial 在
  =q=A^4= 評估，並乘上 =d_j theta_j^f=；
- knot slid over one or more split framed unknots；
- slide 後的 meridian components 用 =S= matrix meridian action 評估；
- =Omega= label 依 =U(C)=Z/2= 加法轉換。

目前測過 right trefoil、left trefoil、figure-eight、=T(2,5)=，以及五種
slide-over framing scenarios，總共 160 個 exact before/after comparisons。
這仍不是 arbitrary multi-component colored-link evaluator；一般 band-sum、任意
planar diagram、dotted/special links 與 closed 4-manifold normalization 仍未涵蓋。

* Fusion-Channel Gate

=experiments/scripts/mtc_fusion_channel_gate.py= 不是 Sage script，但它使用前面
產生的 exact category-data artifact，檢查 non-pointed Hopf-star / central
=Omega= projector 這個中間層：

#+begin_src sh
uv run python experiments/scripts/mtc_fusion_channel_gate.py
#+end_src

預設輸出：

#+begin_src text
experiments/results/mtc-candidates/mtc-fusion-channel-gate-v1.json
#+end_src

目前涵蓋：

- =SU(2)_6= fixed-label Hopf-star fusion-channel controls；
- =SU(2)_6= 343 個三重 fusion associativity checks；
- 一個明確 witness：同樣的 pairwise linking signature 可以因 fusion channel 不同而
  給出不同 =Omega= projector multiplier，所以 non-pointed case 不能只看 linking
  matrix；
- =SU(3)_2= 的 next-candidate readiness gate，目前是 structured blocker，不是
  evaluator：還缺 simple-current character target map 與 full =F/R= backend。
