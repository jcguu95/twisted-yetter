* 給執行代理的最短指示

本計畫要回答的核心問題是：David Yetter 在 1993 年定義的 homologically twisted Crane–Yetter invariant

\[
F_{\mathcal C,X}(\alpha)=Z_{\mathcal C}(X,\alpha),
\qquad
\alpha\in H_2(X;A),
\qquad
A=\operatorname{Aut}_{\otimes}(\operatorname{Id}_{\mathcal C}),
\]

是否可能在適當的 H_2 marking 下區分 homeomorphic but non-diffeomorphic 的 smooth 4-manifolds；以及是否能把它改寫成只使用 Kirby diagram 中 1-handles 與 2-handles 的可計算公式。

立即執行順序如下：

1. 先重建 Yetter 原文的精確定義、normalization 與 \(\mathbb Z/2\) surgical formula；不要先做 triangulation。
2. 把一般 premodular/ribbon fusion category 的候選 twisted Kirby color
   \[
   \Omega_a=\sum_{i\in\operatorname{Irr}(\mathcal C)}d_i\,\lambda_i(a)\,X_i
   \]
   當作「待證命題」，逐一證明 handle-slide、1/2 cancellation、2/3 cancellation 與 basis-change 規則；不要把 \(\mathbb Z/2\) 的直覺直接外推。
3. 同時研究 Reutter 證明是否可延伸到 \(K(A,2)\)-decorated bordism category。這是整個計畫的主要 go/no-go 分岔。
4. 第一個 closed exotic pair 使用 Dolgachev surface \(E(1)_{2,3}\) 與 \(E(1)=\mathbb{CP}^2\#9\overline{\mathbb{CP}}{}^2\)。兩邊都有不含 1-、3-handles 的 explicit handlebody，且有 cork 所給的自然 H_2 identification。
5. 第一個 category 使用低 rank 的 \(SU(2)_2\) 作 negative control 與軟體驗證；不要預期它一定偵測 exotic smoothness。

** 最終研究目標

建立並測試一個可重現的 invariant package：

\[
\mathfrak F_{\mathcal C}(X)
=
\left[H_2(X;A),\;F_{\mathcal C,X}:H_2(X;A)\to k\right],
\]

其中方括號表示要除以適當的 marking change／homeomorphism action。最強目標是找到 exotic pair \((X,X')\)，使兩者的 total decorated functions 即使經過所有允許的 H_2 isometries 仍不相同。

較弱但仍有價值的目標是：

- 在由共同 cork complement 所決定的 canonical marking 下得到 pointwise 差異；
- 證明所有 semisimple decorated theories 仍受某個 decorated Reutter theorem 限制；
- 或證明特定 category 的 twisted invariant 只依賴 intersection form、signature、Pontryagin square、\(w_2\) 等 classical data。

* 核心背景與記號

** Category-side 記號

令 \(\mathcal C\) 為有限半單、spherical、ribbon／premodular category，simple objects 為 \(X_i\)，quantum dimensions 為 \(d_i\)。

Yetter 的「grading group」可用現代 universal grading group 記為

\[
U(\mathcal C)
=
\langle u_i\mid u_k=u_i u_j\text{ whenever }N_{ij}^k>0\rangle.
\]

令

\[
A=\operatorname{Aut}_{\otimes}(\operatorname{Id}_{\mathcal C}).
\]

對每個 \(a\in A\) 與 simple \(X_i\)，Schur lemma 給出 scalar

\[
a_{X_i}=\lambda_i(a)\operatorname{id}_{X_i}.
\]

在適當基域上，Yetter 的 Proposition 4 給出

\[
A\cong \operatorname{Hom}(U(\mathcal C),k^\times).
\]

注意：Yetter 原文的 \(\mathrm{Gr}\mathcal C\) 記號在摘要與正文容易造成混淆。後續工作一律使用 \(U(\mathcal C)\) 表示 universal grading group，使用 \(A\) 表示 tensor automorphism group。

** Manifold-side 記號

對 closed oriented 4-manifold \(X\)，Yetter 的 decoration 可寫為

\[
\alpha\in H_2(X;A)\cong H^2(X;A),
\]

後一個同構由 Poincaré duality 給出。若要把理論提升成 homotopy TQFT/HQFT，應把 \(\alpha\) 視為 homotopy class of maps

\[
X\longrightarrow K(A,2).
\]

定義 total function

\[
F_{\mathcal C,X}:H_2(X;A)\longrightarrow k,
\qquad
\alpha\longmapsto Z_{\mathcal C}(X,\alpha).
\]

** Exotic pair 的比較準則

僅比較某一個任意選定的 \(H_2\) basis 不足以宣稱偵測 smooth structure。至少要區分下列層次：

1. *Marked distinction*：已固定一個自然 identification \(\phi:H_2(X;A)\to H_2(X';A)\)，且存在 \(\alpha\) 使
   \[
   F_X(\alpha)\neq F_{X'}(\phi(\alpha)).
   \]
2. *Cork-canonical distinction*：\(X=N\cup_{\mathrm{id}}C\)、\(X'=N\cup_\tau C\)，由 contractible cork 的共同 complement \(N\) 給出 identification。
3. *Unmarked total-function distinction*：不存在任何 orientation-preserving homeomorphism 所誘導的 \(H_2\) isomorphism 使兩個 functions 相等。
4. *Orbit/multiset distinction*：即使忘記 marking，只保留 \(\{F_X(\alpha)\}_{\alpha}\) 或按 intersection-form automorphism group 分 orbit 後的資料，兩邊仍不同。

論文中必須明確說明得到的是哪一個層次。

* 已建立事實、合理推論與待證命題

** 已建立事實 [ESTABLISHED]

- Yetter 定義了依賴 \(H_2(X;A)\) 的 twisted Crane–Yetter state sum，並證明它與 triangulation 及 cycle representative 無關。
- 在 \(\operatorname{Rep}(U_q\mathfrak{sl}_2)\) 的 \(A=\mathbb Z/2\) 情形，Yetter 給出 simply connected 4-manifold 的 surgical version：
  \[
  \omega=\sum_i\Delta_i i,
  \qquad
  \theta=\sum_i(-1)^i\Delta_i i.
  \]
  代表 decoration 的 2-handle components 標 \(\theta\)，其餘 components 標 \(\omega\)。
- Yetter 證明在 \(\mathbb Z/2\) 情形，滑過 \(\theta\)-component 會交換 \(\omega\leftrightarrow\theta\)，正好對應 homology basis change。
- Reutter 證明 ordinary semisimple oriented 4D TQFT 對 \(S^2\times S^2\)-stable diffeomorphism 不變，因此 ordinary Crane–Yetter–Kauffman theory 不能區分 closed exotic smooth structures。
- Reutter 的 theorem statement 位於 undecorated oriented bordism category；原文沒有直接處理以 \(K(A,2)\) background 標記的 bordisms。
- Akbulut 給出 \(E(1)_{2,3}\) 不含 1-、3-handles 的 explicit handlebody，並把它表示成 \(E(1)\) 的 cork twist。
- Wakamaki 給出 exotic \(R_8\) 與 \(\mathbb{CP}^2\#8\overline{\mathbb{CP}}{}^2\) 的 explicit cork picture，且此 pair 經一次 \(S^2\times S^2\) stabilization 後 diffeomorphic。
- Beliakova–De Renzi 已建立帶 \(H^2(W,\partial W;G)\) decoration 的 4-dimensional 2-handlebody invariants，提供現代 decorated Kirby calculus 的重要模板；但其 equivalence relation 與完整 closed 4D TQFT 問題需分開處理。

** 合理推論 [INFERENCE]

- Yetter twist 可能逃離 Reutter 原 theorem 的直接適用範圍，但這不表示它真的能偵測 exotic smoothness。
- 正確的理論問題應是「decorated/marked stable diffeomorphism」而不是 ordinary stable diffeomorphism。
- modular category 的 twisted theory很可能只產生 finite 2-form gauge theory／quadratic refinement 型資料，因此應先當 negative control。
- explicit cork pair 比任意 exotic pair 更適合，因為共同 complement 提供自然 marking 並可能把計算局部化到 boundary state space。

** 待證命題 [CONJECTURAL UNTIL PROVED]

- 對一般 \(a\in A\)，2-handle 的 twisted Kirby color 應為
  \[
  \Omega_a=\sum_i d_i\lambda_i(a)X_i.
  \]
- 一般 finite abelian \(A\) 下的 handle-slide rule 應由 decoration coordinates 的 basis change 控制；確切是左乘、右乘、inverse 或 contragredient action 必須從 orientation convention 推導，不能猜。
- 一般 premodular category 的 Kirby formula 與 Yetter state sum 應在適當 normalization 下相等。
- cork decomposition 可能給出
  \[
  Z(X,\alpha)-Z(X^\tau,\alpha)
  =\langle Z(N,\alpha),(1-\tau_*)Z(C,0)\rangle,
  \]
  但必須先建立 decorated gluing theory 與 boundary state spaces。

\]

** RQ4：哪些 category 最有機會產生非 classical 的 decorated data？

目標：建立 algebraic screening，不要直接在大型 exotic diagram 上盲算。

** RQ5：哪一組 exotic pair 是第一個可行實驗？

目標：在 diagram size、H_2 marking、known stabilization 與計算複雜度之間最佳化。

** RQ6：如何把指數爆炸降到可計算？

目標：使用 universal-grading sectors、finite Fourier transform、fusion constraints、memoization 與 tensor-network contraction，而不是逐 decoration、逐 coloring 重算。

* 主要 go/no-go 決策樹

** 分支 A：證明 decorated Reutter theorem

若能證明下列組合：

1. Yetter theory 確實延伸為 semisimple \(K(A,2)\)-HQFT；
2. 相關 decorated stabilization operator 可逆；
3. 所需的 H_2 marking 可由 stable diffeomorphism 實現；

則 semisimple closed-theory 路線大概率無法偵測 exotic smoothness。此時專案應轉向：

- non-semisimple ribbon categories；
- 僅對 2-handlebodies／2-deformations 定義的 invariants；
- boundary state／cork action；
- skein-lasagna 或其他不延伸成 ordinary full semisimple TQFT 的模型。

** 分支 B：decorated stabilization 留下真正障礙

若 ordinary stable diffeomorphism 無法在 stabilization 後保持指定 \(\alpha\oplus0\)，或某些 decorated stabilizer amplitudes 不可逆／為零，則進入 explicit exotic-pair 計算。

** 分支 C：category screening 顯示 invariant 完全 classical

若對某 category 可證

\[
F_X(\alpha)=f\bigl(\chi(X),\sigma(X),Q_X,\mathfrak P(\alpha),w_2(X)\smile\alpha,\ldots\bigr),
\]

則把該 category 標為 negative control，不再用它做大型 exotic 計算；改測非模、slightly-degenerate 或 non-semisimple input。

** NEXT WP4.4 finite Fourier transform

對 \(A=\mathbb Z/2\)，先按 universal-grading sector 聚合：

\[
S_b
=
\sum_{\deg(X_j)=b_j}
\Bigl(\prod_j d_{X_j}\Bigr)\operatorname{RT}(L;X_1,\ldots,X_m),
\qquad
b\in(\mathbb Z/2)^m.
\]

再一次性做 Walsh–Hadamard transform：

* Cork-local 計算策略

若能建立 decorated boundary state space，對

\[
X=N\cup_{\mathrm{id}}C,
\qquad
X^\tau=N\cup_\tau C
\]

應嘗試寫成

\[
Z(X,\alpha)=\langle Z(N,\alpha),Z(C,0)\rangle,
\]

\[
Z(X^\tau,\alpha)=\langle Z(N,\alpha),\tau_*Z(C,0)\rangle.
\]

此路線把大型 closed link 計算拆成：

1. 求 cork boundary 的 state space；
2. 求 involution \(\tau_*\) 的矩陣；
3. 求 complement state 隨 \(\alpha\) 的變化；
4. 測試 complement state 是否投影到 \((1-\tau_*)\) 的非零部分。

若成功，這可能比直接評估兩張完整 Kirby links 更有效，也能清楚定位 exotic smoothness 的來源。

* Homeomorphism-group 與 orbit 比較

對 simply connected indefinite odd unimodular form，需計算 integral intersection-form automorphism group 在 \(H_2(X;A)\) 上的 image。對 \(A=\mathbb Z/2\)，至少記錄：

- \(\alpha\cdot\alpha\bmod2\)；
- \(\alpha\) 是否 characteristic；
- pairing with \(w_2\)；
- integral lift 的 divisibility（若 decoration group 不是純 mod 2）；
- canonical class／fiber class 等 pair-specific structures是否由 marking 固定。

結果報告分三層：

1. raw basis coordinates；
2. cork-canonical marking；
3. quotient by all known homeomorphism-induced automorphisms。

只有第 3 層的差異才接近「unmarked exotic smooth structure detection」。

* 驗收標準

** 理論驗收

- 所有 decoration conventions 清楚且在 handle slides 下可機械檢查。
- 一般 Kirby formula 的適用假設明確：modular、premodular、spherical、semisimple、有限 \(A\) 等不能含糊。
- 2/3 cancellation 與 implicit 3-handles 被真正處理；不能只證 2-handlebody invariance 卻宣稱 closed 4-manifold invariant。
- 與 Yetter \(\mathbb Z/2\) formula 精確相符。
- 對 Reutter theorem 的任何「逃脫」或「延伸」都指出缺失的 hypothesis。

** 計算驗收

- standard manifolds 的已知 ordinary values 可重現。
- handle-slide 前後 exact equality。
- Fourier 與 direct computation 在小例子相符。
- Dolgachev/R_8 diagram 的 linking matrix、signature、Euler characteristic 正確。
- H_2 identification matrix 可審計。
- 結果可由單一命令重跑。

** 宣稱 exotic detection 的最低標準

至少滿足：

1. pair 已知 orientation-preservingly homeomorphic but not diffeomorphic；
2. decoration correspondence 有明確拓撲來源；
3. exact values 不同；
4. 已排除 normalization 與 basis artifact；
5. 清楚說明差異是否在 homeomorphism-group quotient 後仍存在。
