* Category Data

使用 =SU(3)_3=：

- rank 10；
- simple labels：
  =(0,0), (1,0), (0,1), (2,0), (1,1), (0,2), (3,0), (2,1), (1,2), (0,3)=；
- universal group 是 =Z/3=；
- degree formula 是 =deg(a,b)=a+2b mod 3=；
- simple-current row targets：
  =0 -> (0,0)=、=1 -> (3,0)=、=2 -> (0,3)=；
- =Omega_a= Hopf projector targets 要取 dual：
  =0 -> (0,0)=、=1 -> (0,3)=、=2 -> (3,0)=。

Multiplicity witness：

#+begin_src text
(1,1) tensor (1,1) = (0,0) + (3,0) + (0,3) + 2*(1,1)
#+end_src

這是本輪選 =SU(3)_3= 的主因：它不只是 =Z/3=，而且 fusion multiplicity 已經
不是 0/1。

關鍵 convention correction：

#+begin_src text
framed meridian-slide sector transform:
  a -> a - sum_r f_r b_r  mod 3

其中 =a= 是被 slide 的 component 的 =Omega= sector，=b_r= 是各個 slide-over

#+end_src

而不是 closed Hopf link normalization：

#+end_src

* 判斷

目前得到的是 strong category-level symbolic evidence：

- 目前所有已用過的 Kirby-move classes 都已在 =SU(3)_3= 上通過；
- =SU(3)_3= 同時測到 =Z/3=、非自對偶 simple-current target、以及 fusion multiplicity；
- 這比 =SU(2)_2= / =SU(2)_6= 更能排除「只是 =Z/2= 太簡單」造成的假陽性。

但仍不可宣稱：

- 已有 arbitrary =SU(3)_3= link evaluator；
- 已有 full =F/R= planar tensor-network evaluator；
- 已處理 dotted/special links；
- 已有 closed 4-manifold normalization；
- 已計算 exotic pair。

* 下一步

若要繼續突破目前邊界，下一個自然方向不是再加更多同型 symbolic checks，而是：

- 建立真正的 local-piece / =F,R,eval,coeval= evaluator；
- 或至少先支援一個具體 nontrivial multi-component link whose value cannot be reduced
  to the current meridian/fusion-channel formulas；
- 然後再把 =SU(3)_3= 作為 regression target，確認 full evaluator 與本輪 symbolic
  identities 一致。
