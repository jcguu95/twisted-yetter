* 方法

固定 label assignment 的 evaluator：

1. 找出 closure components 與 strand-to-component map。
2. 若有 =sigma= components，取出 =sigma= strands 的 selected subbraid。
3. =sigma= sublink 用 B1' explicit =R/F= backend 評估。
4. =psi= 作為 invertible object，用 =psi=-=sigma= linking factor：

   #+begin_src text
   (-1)^(sum linking(psi_component, sigma_component))
   #+end_src

5. component framing 乘上 twist。
6. =Omega_a= 用：

   #+begin_src text
   Omega_a = sum_i d_i (-1)^(a deg(i)) X_i
   #+end_src

7. 對所有 fixed labels 求和。

braid oracle 只作 independent exact comparison，不作主要計算。
