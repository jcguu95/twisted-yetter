* Test 0: Encircling Projector

Normalized projector:

#+begin_src text
P_a(j) = sum_i S_{0i} chi_a(i) S_{ij}
#+end_src

Result:

#+begin_src text
a = 0:
  P_0(0)=1
  P_0(1)=0
  P_0(2)=0

a = 1:
  P_1(0)=0
  P_1(1)=0
  P_1(2)=1
#+end_src

Interpretation:

#+begin_src text
Omega_0 / D projects to simple object 0.
Omega_1 / D projects to simple object 2.
#+end_src

This is the first nontrivial mechanism: the twisted Kirby color is not the
ordinary vacuum projector.

* Current Interpretation

The tests support the following working understanding:

1. =Omega_1= is not a vacuum projector; in =SU(2)_2= it projects to the
   invertible simple object =2=.
2. The nontrivial twist changes small raw values, sometimes only by sign and
   sometimes more substantially.
3. Basic handle-slide tests pass when cohomology labels transform by the
   handle-basis change.
4. The trefoil test uses actual =R=-symbol data and is not just a Hopf
   =S=-matrix shortcut.
5. The three-component pressure test suggests that the label-transform rule is
   not only a one-slide accident in these =SU(2)_2= examples.

The next useful pressure test should either introduce negative crossings /
mirror trefoils or move toward a small general braid-word evaluator, still
before touching exotic-pair diagrams.
