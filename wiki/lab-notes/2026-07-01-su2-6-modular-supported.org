* Exact Controls

script 產生的 certificate 狀態為 =pass=。

modular controls 共 9 個：

- =s_matrix_symmetric=
- =s_square_is_identity=
- =hopf_row_zero_is_dimension=
- =fusion_dimension_algebra=
- =universal_degree_respects_fusion=
- =omega_coefficients_match_degree_characters=
- =simple_current_character_matches_degree=
- =omega_hopf_projector_identity=
- =omega_hopf_pair_closed_form=

最後三個是本輪補上的去水 controls：

- =simple_current_character_matches_degree= 檢查 simple current =6= 的 =S=
  matrix row 確實給出 =(-1)^j= character。
- =omega_hopf_projector_identity= 檢查 =Omega_0= encircling projector 只留下
  label =0=，而 =Omega_1= encircling projector 只留下 simple current label =6=。
- =omega_hopf_pair_closed_form= 檢查 zero-framed Hopf pair 的
  =Omega_a, Omega_b= exact value 等於 global dimension，這不是單純比較同一個
  展開的兩種 JSON 包裝。

supported evaluator controls 共 4 個：

- single framed unknot with framing =+1=
- split union of two framed unknots with framings =+1,-1=
- positive Hopf pair with zero framings
- split union of framed Hopf pair and framed unknot

每個 supported control 都比較兩種計算：

1. 直接把 =Omega_a= 展開成 simple labels 後求和。
2. 使用 certificate 中記錄的 =Omega= sector coefficients 再求和。

兩者 exact 相等。

* Supported Link Class

目前只支援 split union of supported blocks：

- =framed_unknot=
- =positive_hopf_pair=

其 fixed-label value 分別由下列 modular data 決定：

#+begin_src text
framed unknot:
  d_i * theta_i^framing

positive Hopf pair:
  (S_ij / S_00) * theta_i^framing_i * theta_j^framing_j
#+end_src

split union 的 value 取 block-wise product。

這個限制很重要：它不是任意 linking matrix evaluator，也不是任意 =SU(2)_6=
colored link evaluator。

* Explicitly Rejected

certificate 明確拒絕：

- arbitrary linking matrix
- trefoil or other nontrivial knot component
- general braid closure
- Borromean rings
- Hopf-star / one component encircling multiple nontrivial components
- any diagram needing =F=-symbol or =R=-symbol fusion-space traces

尤其 Hopf-star 不能只靠 pairwise linking data 評估。原因是 =SU(2)_6= 不是 pointed
category；一個 central loop 圍住多個 component 時，value 會依賴被圍住 labels
的 fusion channel，而不只是每對 component 的 linking number。
