* B0 Schema

新的 repo-local schema：

#+begin_src text
twisted-yetter.local-piece-program.v1
#+end_src

目前支援：

#+begin_src text
piece kind:
  braid_crossing

closure kind:
  braid_closure
#+end_src

每個 =braid_crossing= 是一個 local =R= 或 =R^{-1}= piece：

#+begin_src text
left_index = braid generator index
sign       = +1 or -1
#+end_src

程式會從 pieces compose 出 braid word，然後由 closure permutation 決定 component
ordering、component count、linking matrix sanity check，最後產生既有
=su2_2_braid_oracle= 可吃的 payload。

* 判斷

這是一個真正前進的 evaluator-track scaffold，因為現在資料流已經是：

#+begin_src text
local pieces
  -> compositional program
  -> closure/component diagnostics
  -> exact categorical backend
  -> reproducible certificate
  -> pytest regression
#+end_src

但它仍然不可宣稱：

- 任意 oriented planar diagram evaluator；
- full =F/R= tensor-network evaluator；
- cup/cap/eval/coeval support；
- special/dotted Kirby component support；
- closed 4-manifold invariant evaluator；
- exotic-pair computation。
