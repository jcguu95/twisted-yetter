* Candidate 2: Vec_{Z/3}^q

選擇：

#+begin_src text
A = Z/3
q(x) = zeta_3^(x^2)
b(x,y) = q(x+y)/(q(x)q(y)) = zeta_3^(2xy)
#+end_src

Universal group:

#+begin_src text
U(C) = Z/3
deg(x) = x
simple labels = 0,1,2
fusion = addition mod 3
#+end_src

這是目前最乾淨的 =U(C)>Z/2= 測試場。因為它是 pointed，fixed-label framed
link evaluation 只需要 linking matrix：

#+begin_src text
value(x_1,...,x_n)
  = product_i theta_{x_i}^{Q_ii}
    product_{i<j} b(x_i,x_j)^{Q_ij}
#+end_src

本輪加入 27 個 pointed handle-slide controls。若 slide =K_1 <- K_1 + K_2=，
matrix 用：

#+begin_src text
Q' = B^T Q B,   B columns = new basis vectors in old basis
#+end_src

Omega labels 則用：

#+begin_src text
(a,b) -> (a+b, b) mod 3
#+end_src

全部通過。

** Vec_{Z/3}^q Pointed Stress Suite

接著把 =Vec_{Z/3}^q= 擴成真正的 linking-matrix / Kirby basis-change stress
suite。這一類 category 是 pointed，所以 fixed-label framed link evaluation 不需要
=F/R= evaluator；對 linking matrix =Q= 和 simple labels =x_i in Z/3=：

#+begin_src text
value_Q(x)
  = product_i q(x_i)^{Q_ii}
    product_{i<j} b(x_i,x_j)^{Q_ij}

q(x)=zeta_3^(x^2)
b(x,y)=zeta_3^(2xy)
#+end_src

再展開 twisted Kirby color：

#+begin_src text
Omega_a value
  = sum_x zeta_3^{sum_i a_i x_i} value_Q(x)
#+end_src

若 =B in GL(n,Z)= 的 columns 是 new basis vectors written in old basis，則：

#+begin_src text
Q' = B^T Q B
a' = B^T a mod 3
#+end_src

stress suite 覆蓋：

#+begin_src text
sizes = 1,2,3,4,5
basis moves = elementary slides, swaps, orientation reversals, compound moves
total moves = 121
total Omega comparisons = 17589
failures = 0
#+end_src

每個 comparison 都真的檢查：

#+begin_src text
Omega_a(Q) == Omega_{B^T a}(B^T Q B)
#+end_src

初版直接用 Sage field element 在內層展開，跑約 95 秒；後來改成先做純 =mod 3=
Gauss-sum exponent counting，再轉回 =CyclotomicField(3)=，同樣檢查範圍降到約 5 秒。

=SU(3)_1= 是 pointed，太像 =Vec_{Z/3}^q=；所以 first interesting non-pointed
candidate 選：

#+end_src

simple labels：

#+begin_src text
(0,0), (1,0), (0,1), (2,0), (1,1), (0,2)
#+end_src

重要 tensor product sanity checks：

#+begin_src text

這正是離開 =SU(2)_2= 後必須做對的地方：tensor product 不是一個 simple object，
而是 direct sum over fusion channels。artifact 以 =N_{ij}^k= 形式記錄 fusion
multiplicities。
