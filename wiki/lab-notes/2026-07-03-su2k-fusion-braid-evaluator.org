* 已通過的 controls

新 evaluator 的 =--self-test= 目前通過以下 =SU(2)_2= checks：

1. two-component sigma unlink：
   \( \langle U_\sigma \sqcup U_\sigma\rangle = d_\sigma^2 = 2 \)。

2. sigma-sigma positive Hopf：
   值為 \(0\)，符合 Ising \(S_{\sigma,\sigma}=0\)。

3. psi-sigma positive Hopf：
   值為 \(-\sqrt 2\)，符合既有 =su2_2_braid_oracle= convention。

4. right trefoil with sigma label and zero external framing：
   值為 \(-\sqrt 2\)，符合既有 oracle。

#+begin_src text

#+end_src

代表目前不能把這個 evaluator 用在 =SU(2)_6= Yasui computation。

* 已修掉的中間錯誤

1. Dense =QQbar= matrix multiplication 太慢。
   改成 sparse path propagation 後，某些 =SU(2)_6= fixed sector 從約 24 秒降到
   約 0.17 秒。

2. Unit-colored components 不能直接留在 full braid trace 裡。
   已改成先刪掉 unit-colored components，抽出 selected subbraid。

3. 抽 selected subbraid 後 component order 不能沿用原本 nonzero component order。
   已新增 selected subcomponent -> original component lineage。

4. 第二個 F-move 必須用 \(F^{-1}\)，不能假設 F 自己就是 inverse。

5. q-6j face placement 曾經把一些合法 unit/nonunit channel 算成 0。
   已修成 associator faces：

#+begin_src text
(a,b,e), (e,c,d), (b,c,f), (a,f,d)
#+end_src

* 目前 blocker 的形狀

局部 braid generators 在小型 =SU(2)_2= examples 上可對上，但完整 Yasui
multi-component sectors 仍不對。可能原因：

#+begin_src text
1. 手寫 q-6j gauge 尚未與 Sage / Jones oracle convention 完全一致。
2. Markov trace / colored closure formula 對多 component closure 的 normalization
   還缺少 convention factor。
3. mixed labels involving invertible object 2 與 sigma 的 braid/trace convention
   仍有錯。
#+end_src

因此 =experiments/results/yasui/figure3-a1-other-mtc-comparison-v1.json= 現在把
=SU(2)_6= 標成：

#+begin_src text
blocked-fusion-braid-calibration-failed
#+end_src

這是故意的防呆：不要讓未來 agent 誤用目前 scaffold。

* 下一步建議

下一步不應直接算 =SU(2)_6=，而應先做 calibration-focused work：

1. 用 Sage =FusionRing.get_braid_generators= 在 all-sigma \(n=4,5,\dots\) cases 上
   比較 trace，而不只比較 generator matrices。

2. 對 =SU(2)_2= Yasui payload 建立完整 fixed-sector mismatch artifact：
   每個 labels sector 記錄 oracle value、fusion evaluator value、difference。

3. 優先解釋 sectors：

#+begin_src text
(1,1,2)
(1,1,0)
(0,1,1)
(1,1,1)
#+end_src

4. 若 q-6j gauge 持續難修，改走 Kauffman bracket / Jones-Wenzl cabling route，
   先求一個可靠的 =SU(2)_k= colored-link evaluator，再回頭一般化到 F/R backend。
