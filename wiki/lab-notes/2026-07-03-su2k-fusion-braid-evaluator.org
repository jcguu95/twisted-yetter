* 已修掉的中間錯誤

1. Dense =QQbar= matrix multiplication 太慢。
   改成 sparse path propagation 後，某些 =SU(2)_6= fixed sector 從約 24 秒降到
   約 0.17 秒。

2. Unit-colored components 不能直接留在 full braid trace 裡。
   已改成先刪掉 unit-colored components，抽出 selected subbraid。

3. 抽 selected subbraid 後 component order 不能沿用原本 nonzero component order。
   已新增 selected subcomponent -> original component lineage。

4. 第二個 F-move 必須用 \(F^{-1}\)，不能假設 F 自己就是 inverse。

5. q-6j face placement 曾經把一些合法 unit/nonunit channel 算成 0。
   已修成 associator faces：

#+begin_src text
(a,b,e), (e,c,d), (b,c,f), (a,f,d)
#+end_src

** 修正項目

1. =crossing_entries= 的 prefix indexing 有 off-by-one 類錯誤。
   對 generator index =1=，prefix 應是第一條 strand 的 label，而不是
   =path[-1]=。修正後，all-=sigma= generator traces 在 \(n=4,5\) controls
   上與 Sage =FusionRing.get_braid_generators= 對齊。

2. =R=-symbol 的 sign convention 對 mixed simple labels 過強。
   與 Sage all-=sigma= controls 比對後，目前只在 =left == right= 時套用
   \((-1)^{(left+right-output)/2}\) sign。

3. 為了與既有 =SU(2)_2= braid oracle 的 multi-component convention 對齊，
   加入了 even-level degree-linking phase：

#+begin_src text
phase = A^(((k+2)/2) * sum_{i<j, labels_i odd, labels_j odd} lk(i,j))
#+end_src

   這一步目前應視為 convention calibration，不應升格為一般 theorem。

4. =exact=False= 時新增 NumPy dense matrix backend。數學語義仍是同一個
   fusion-path braid action；差別只是把每個 total charge sector 的矩陣乘法交給
   BLAS，而不是用 Python/Sage sparse dictionary compose。

#+begin_src text

Kirby calibration，而不是把這個 mismatch 當作四維不變量的數值。
