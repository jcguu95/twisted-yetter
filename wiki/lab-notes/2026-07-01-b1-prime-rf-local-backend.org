* 關於 Braid Closure 與一般 Link

長期目標不是要求人類或 Kirby diagram digitization 都輸入 braid closures。
研究輸入應該是 Kirby / planar / local-piece graph friendly 的格式。

但在早期階段，braid closure 是很好的 backend route：

- Alexander theorem 保證 oriented link 可以 braid 化；
- 既有 Sage / Jones / oracle backend 可作 regression；
- local crossing pieces 本來就自然 compose 成 braid word；
- 等 cup/cap/eval/coeval tensor graph 成熟後，可逐步替換 backend。

所以目前策略是：

#+begin_src text
human/research input:
  Kirby diagram / planar diagram / local-piece graph

temporary exact backend:
  braid closure where convenient

future backend:
  full F/R/eval/coeval tensor contraction
#+end_src

* Yasui Exotic Pair Test 想法

插播討論中形成的下一個 research-facing route：

1. 和使用者一起從 Yasui paper 整理一組具體 exotic pair 的 Kirby presentation。
2. 先做 untwisted MTC / ordinary Crane-Yetter negative control。
3. 若兩邊 untwisted 不同，優先視為 evaluator、normalization、presentation 或 handle
   bookkeeping bug。
4. 若 untwisted 相同而 twisted 不同，這會是非常強的 positive signal。

這條路很值得走，但不應和 B1' backend commit 混在一起。B1' 先把 evaluator
infrastructure 往 local categorical contraction 推進。
