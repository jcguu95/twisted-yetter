* Method

輸入是一個 oriented braid closure：

#+begin_src json
{
  "n_strands": 2,
  "braid_word": [1, 1, 1],
  "framings": [0],
  "omega_labels": [1]
}
#+end_src

固定 simple labels 後：

1. =0= labeled components 視為 unit。
2. =1= labeled components 形成 =sigma= sublink；用 Sage 的
   =jones_polynomial(skein_normalization=True)=，在 =A=zeta_16= 評估。
3. 校準使 0-framed =sigma= unknot 的值為 =sqrt(2)=。
4. =2= labeled components 是 invertible =psi=；它與 =sigma= 的 linking 乘上
   =(-1)^lk=。
5. 每個 component 再乘 =theta_label^framing=。
6. =Omega_a= 由
   =sum_i d_i (-1)^{a deg(i)} i= 展開。
