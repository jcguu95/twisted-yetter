* Convention

Each crossing is recorded as:

#+begin_src text
X Y Z W
#+end_src

where:

- \(X\to Z\) is the understrand;
- \(Y,W\) are the overstrand endpoints;
- \(X,Y,Z,W\) are listed counterclockwise around the crossing;
- component arc labels increase cyclically.

The overstrand orientation is inferred from component arc order. For example,
if \(Y\to W\) follows the component orientation, the local sign used by the sanity
script is \(+1\); if \(W\to Y\) follows the component orientation, it is \(-1\).
This sign convention is a working convention for input sanity only and must be
calibrated against a known positive crossing before evaluator use.
