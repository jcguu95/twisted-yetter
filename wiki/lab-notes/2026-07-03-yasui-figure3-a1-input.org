* Convention

Each crossing is recorded as:

#+begin_src text
X Y Z W
#+end_src

where:

- \(X\to Z\) is the understrand;
- \(Y,W\) are the overstrand endpoints;
- \(X,Y,Z,W\) are listed counterclockwise around the crossing;
- component arc labels increase cyclically.

The overstrand orientation is inferred from component arc order. For example,
if \(Y\to W\) follows the component orientation, the local sign used by the sanity
script is \(+1\); if \(W\to Y\) follows the component orientation, it is \(-1\).
This sign convention is a working convention for input sanity only and must be
calibrated against a known positive crossing before evaluator use.

* Braid Conversion

新增 Sage conversion script:

#+begin_src sh
DOT_SAGE="$PWD/.sage" sage experiments/sage/yasui_figure3_a1_to_braid.sage.py
#+end_src

最初嘗試直接用 Sage 的 =Link(PD).braid()=，但該裸 PD 入口對 crossing sign /
component orientation 的 convention 會重新詮釋，產生的 braid closure linking matrix
無法和上面的 Yasui 圖校準目標對齊。因此正式 script 不採用裸 =Link(PD)=。

目前正式 pipeline 是：

1. 從 source crossing table 和 component arc order 建立 oriented Gauss code。
   在 Sage oriented Gauss code 中，positive entry 表示該 component 在該 crossing
   走 over，negative entry 表示走 under。
2. crossing sign 先使用 calibration script 已驗過的 raw oriented-drawing 規則：
   overstrand 若按 =Y -> W= 方向走，sign 為 \(+1\)；若按 =W -> Y= 方向走，
   sign 為 \(-1\)。
3. raw oriented-drawing 規則會得到 \(A-B=-2\)，使得三條 2-handle 的 full
   linking/framing matrix determinant 變成 \(-63\)，不可能是
   \(CP^2\#2\overline{CP^2}\)。因此 evaluator payload 必須校準到 Yasui 圖上
   寫出的 homology / Kirby target matrix。
4. 校準方式：switch 全部 \(A-B\) crossings：
   =x04,x05,x08,x09,x13,x15=。這會把 source-ordered off-diagonal matrix
   變成 \(A-B=2,A-C=4,B-C=2\)，full matrix determinant 為 \(1\)。
5. 用 =Link([component_words, crossing_signs]).braid()= 產生 braid closure。
6. 用 braid closure linking matrix 反推出 braid component order 對應 source components
   \(A,B,C\) 的 permutation。
7. 依該 order 排列 framings，產生 =twisted-yetter.local-piece-program.v1=
   evaluator payload。
8. 對所有 \(A=(\mathbb Z/2)^3\) sectors 跑 =SU(2)_2= =Omega_a= evaluator。
