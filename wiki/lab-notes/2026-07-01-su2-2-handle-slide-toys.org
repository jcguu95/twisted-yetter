* Example 7: Mixed Framing True Band-Sum

這是本輪最重要的修正點。若 =K_1= slides over =K_2=，old linking matrix

#+begin_src text
Q = [[f_1, l],
     [l,   f_2]]
#+end_src

在 new basis =e_1' = e_1 + e_2=, =e_2' = e_2= 下變成

#+begin_src text
Q' = [[f_1 + 2l + f_2, l + f_2],
      [l + f_2,         f_2]]
#+end_src

因此即使 slide 前兩個 components split，也就是 =l=0，只要 slide-over component 有
framing =f_2 != 0=，slide 後就不只是把 =K_1'=K_1#K_2= 的 self-framing 改成
=f_1+f_2=；它還必須和保留下來的 =K_2= 有 linking number =f_2=。

本輪一開始的 naive mixed-framing model 正是漏掉這個 off-diagonal term，所以 fail。
修正後的 after braid 在 band-sum base word 後面加上 =sigma_3^{2f_2}= 的 tail
（目前只宣稱 =f_2= 為 =-1= 或 =+1= 的手寫 local model）。

測試 cases：

#+begin_src text
(f_1,f_2) = ( 1,-1)
(f_1,f_2) = ( 2,-1)
(f_1,f_2) = ( 0, 1)
(f_1,f_2) = (-1, 1)
#+end_src

label rule 仍然是：

#+begin_src text
before labels = (a,b)
after labels  = (a+b,b)
#+end_src

全部 16 個 comparisons 通過：

#+begin_src text
source_test = true-band-sum-3
comparisons = 16
status = pass
#+end_src

重要 boundary：

- =|f_2|>1= 尚未宣稱涵蓋。
- 要處理任意 framing，應該先做一個真正的 framed push-off / cabling constructor。
- 這個 test 的價值是先把 =Q'=B^TQB= 的 framing/linking bookkeeping 防呆。
