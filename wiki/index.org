* 當前重點

本 repo 有兩條互相支援的工作線：

- twisted Yetter invariant 的數學與計算研究；
- object-first lab note / CTL kernel，用來讓長期研究紀錄可重放、可審計、可由未來 agent 接手。

目前 CTL kernel 只是一個 conformance scaffold；它的存在是為了讓 lab note governance 先有可執行核心，不代表 twisted Yetter 數學部分已經開始計算。
