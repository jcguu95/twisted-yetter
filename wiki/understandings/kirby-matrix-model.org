* 狀態

狀態標籤：=n20-kirby-matrix-model= / =working understanding= / =matrix-level only=

本頁記錄目前最小 integer linking/intersection matrix model。這不是 Kirby diagram
parser，也不是 twisted Yetter invariant formula；它只提供小型 toy examples 與
GL(n,Z) basis change 的可測試 convention。

* Matrix convention

- 一個 presentation 由 symmetric integer matrix =Q=、component IDs、orientation
  labels、以及可選的 =A = Z/2= decoration coordinate vectors 組成。
- diagonal entries 是 framings。
- parity 採 integral form 的標準 convention：所有 diagonal entries 皆為 even 時稱
  =even=，否則為 =odd=。
- determinant、rank、signature 皆用 Python =int= / =fractions.Fraction= exact
  arithmetic；浮點數不作為 evidence。

* Basis change convention

若 unimodular matrix =P in GL(n,Z)= 的 columns 是「new basis vectors written in the
old basis」，則 form matrix 變換為：

#+begin_src text
Q_new = P^T Q_old P
#+end_src

Decoration vector 視為同一 homology class 在 basis 中的 coordinate column vector。
因此座標 contravariantly 變換：

#+begin_src text
x_old = P x_new
x_new = P^{-1} x_old
#+end_src

目前 =src/twisted_yetter/linking_matrix.py= 只實作 =A = Z/2= toy decorations，所以
=P^{-1} x_old= 會再 reduction modulo 2。
