本頁記錄 elementary colored framed link controls 的最小資料/測試層。這些 controls 是
RT/Kauffman local convention 的 =SOURCE NEEDED/local-convention/schema-test-safe= 目標；
它們不是 Hopf/crossing evaluator、Kirby formula、ordinary 或 twisted 4D invariant。

* Exact Value Contract

實作使用 exact arithmetic only：

- quantum dimension part：=QuadraticSurd=，也就是 \(Q(\sqrt 2)\)。
- framing twist part：=RootOfUnityPower(16, exponent)=，也就是 symbolic
  \(\zeta_{16}^{exponent}\)。

對 =SU(2)_2= simple label \(i\) 與 integer framing \(f\)，local target 是：

#+begin_src text
empty link = 1
0-framed colored unknot = d_i
integer-framed colored unknot = theta_i^f * d_i
split unlink = product of component controls
#+end_src

目前 twist sign convention 仍依照 =su2_level2.py= 的 =SOURCE NEEDED/local-convention=
資料；這裡只把 contract 做成 exact、可測、可傳遞給後續 evaluator gate 的形式。

* Machine-Readable Fixture Coverage

測試從 =experiments/inputs/toy-diagrams/= 讀取至少三種 no-crossing toy fixtures：

- =s4-empty.json=：empty link control，expected value =1=。
- =cp2-plus-one-framed-unknot.json=：single +1-framed unknot control；在 label =2=
  時 expected value 是 \(\zeta_{16}^{8}\cdot 1\)。
- =unlink-two-component.json=：split unlink multiplicativity control；例如 label
  =(1,1)= 時 value 是 \(\sqrt 2\cdot\sqrt 2=2\)。

=hopf-link.json= 與 =s2x-s2-hopf-zero-framed.json= 含 crossings；本 node 明確拒絕
crossing evaluation，Hopf / crossing controls 留給 =n17-hopf-and-crossing-controls=。

* Boundary

這個 node 可以 support：

- 後續 evaluator 從 =LinkDiagram= fixture 進入；
- elementary no-crossing expected values 的 exact regression tests；
- framed unknot twist contract 的 symbolic tests。

這個 node 不 support：

- Hopf link 或一般 crossing link evaluation；
- Kauffman bracket skein / RT recoupling evaluator；
- Kirby-color sum、signature anomaly、handle cancellation normalization；
- closed 4-manifold invariant 或 exotic detection claim。
