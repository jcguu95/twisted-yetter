* Working Target, Not A Sourced Theorem

Existing project notes contain the following working target for the =A = Z/2= case:

\[
\omega \sim \sum_i \Delta_i i,\qquad
\theta \sim \sum_i (-1)^i\Delta_i i.
\]

This note treats that display only as a =SOURCE NEEDED= search target.  The repo has not yet pinned:

- whether Yetter's source uses exactly this notation;
- whether \(\Delta_i\) equals the quantum dimension \(d_i\), a bracket loop value, or another
  convention-dependent coefficient;
- the index set and parity convention in \((-1)^i\);
- the category hypotheses and root-of-unity conventions;
- the normalization and signature factor;
- whether the statement is a closed-manifold invariant theorem, a restricted surgery expression,
  or a presentation-level computation.
