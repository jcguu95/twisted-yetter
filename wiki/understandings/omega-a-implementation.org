This node implements a minimal coefficient-metadata scaffold for the candidate display

\[
\Omega_a = \sum_i d_i\lambda_i(a)X_i.
\]

This is =computed evidence= for deterministic exact metadata only.  It is not a theorem, not
a sourced homologically twisted Kirby color, not a link evaluator, not a decorated Kirby-move
proof, and not a closed 4-manifold invariant.

* Scope

Supported finite \(A\) data:

- trivial group, from =twisted_yetter.finite_groups:TRIVIAL_GROUP=;
- \(Z/2\), from =twisted_yetter.finite_groups:Z2_GROUP=.

Unsupported:

- other finite abelian groups;
- nonabelian groups;
- approximate roots of unity or floating point character tables;
- link evaluation, Kirby color sums over diagrams, handle slides, decorated cores, closed
  normalization, or exotic-pair comparison.

Each sector is indexed by a group element \(a\).  Each simple label \(i\) records:

- ordinary dimension coefficient \(d_i\) in \(Q(\sqrt 2)\);
- assigned character label \(\lambda_i\);
- exact integer character value \(\lambda_i(a)\);
- candidate product \(d_i\lambda_i(a)\) in \(Q(\sqrt 2)\).

* Trivial A Specialization

For the trivial group, every =SU(2)_2= simple label is assigned the unique trivial character.
The only sector has coefficients equal to the current ordinary omega scaffold:

#+begin_src text

label 1 -> sqrt2
label 2 -> 1
#+end_src

This is a =candidate-experimental= specialization check.  It inherits the ordinary surgery gate
blocker and does not upgrade =omega = sum_i d_i X_i= to a sourced surgery formula.

* Z/2 Local Assignment

For \(Z/2\), the current local label-to-character assignment is:

#+begin_src text
label 0 -> chi_0
label 1 -> chi_1
label 2 -> chi_0
#+end_src

Therefore the nontrivial group element sector has sign-weighted coefficients
\((1, -\sqrt2, 1)\) for labels \(0,1,2\).

Status of this assignment:

- =candidate/local=;
- not sourced as a Yetter theorem;
- intended only as an explicit convention slot for later =n31= / =n36= comparison.

If future source capture changes the \(\theta\)-target convention, this assignment should be
updated or falsified rather than silently preserved.
