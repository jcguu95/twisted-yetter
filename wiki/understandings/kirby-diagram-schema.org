* 狀態

狀態標籤：=n12-kirby-diagram-schema= / =working understanding= / =input-schema only=

本頁記錄 repo-local Kirby/link diagram input schema v1。這一層只負責把 framed
oriented link diagram 用 machine-readable JSON / Python object 表示，並做基本
validation。它不是 RT link invariant evaluator，也不是 Kirby-color surgery formula，
更不是 twisted Yetter calculator。

* Schema v1

Python implementation：=src/twisted_yetter/link_diagram.py=

JSON schema tag：

#+begin_src text
twisted-yetter.link-diagram.v1
#+end_src

一個 diagram payload 至少包含：

- =diagram_id=：非空字串。
- =components=：component records。
- =crossings=：signed over/under crossing records。
- =description=：可選的人類說明。

每個 component record 包含：

- =id=：component id。
- =framing=：整數 framing。
- =dotted=：boolean，保留 Kirby 1-handle metadata；目前不解釋 dotted semantics。
- =orientation=：=+= 或 =-=。

每個 crossing record 包含：

- =id=：crossing id。
- =sign=：=+1= 或 =-1=。
- =over=：={component_id, arc_id}=。
- =under=：={component_id, arc_id}=。

這是 PD-code-like 的最小 crossing record：它記錄 over/under、sign、component 與
arc id，但還不是完整 planar adjacency encoding。後續 =n13= / =n16= / =n18= 若需要
真正 RT evaluator，可在不破壞 component/framing schema 的前提下擴充 planar data。

* Linking matrix sanity check

=LinkDiagram.linking_matrix()= 只作為 schema sanity check：

- diagonal entries 來自 component framings；
- off-diagonal entry 是兩 component 之間 signed crossing sum 的一半；
- inter-component signed crossing sum 若不是 even，視為不適合作為 linking-number
  sanity check 的 malformed toy input。

這個 matrix 可轉成既有 =KirbyMatrixPresentation=，但不能反過來把 matrix statistic
當成 link invariant evaluator。

* Trust boundary

本 node 完成後仍未完成：

- planar isotopy / Reidemeister move evaluator；
- RT / Kauffman bracket colored framed link evaluation；
- Kirby color summation；
- ordinary Crane-Yetter / Yetter normalization；
- H2 label / general A candidate formula；
- exotic pair calculation。

換句話說，=n12= 只讓未來 calculator 有正確型別的輸入，不提供 calculator 本身。
