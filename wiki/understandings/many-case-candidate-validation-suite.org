* Trust Boundary

Passing the suite means:

- n35 decorated-core artifacts for the listed cases pass metadata validation;
- JSON serialization is stable;
- serialized JSON contains no float marker such as =.0=;
- source/claim boundary fields are present;
- zero and nonzero \(Z/2\) sectors are represented.

Passing the suite does not mean:

- the candidate \(\Omega_a\) formula is proved;
- a link was evaluated;
- a Kirby color sum was computed;
- a decorated Kirby move was checked;
- a closed 4-manifold invariant exists;
- any exotic smooth pair has been distinguished.

* Unblocks and Remaining Blockers

  metadata summaries instead of constructing ad hoc decoration inputs;
- presentation/pair generator nodes can reuse the case summary shape for
  metadata-only dry runs.

Still blocked:

- =n24-ordinary-surgery-gate=;
- source-audited Yetter \(Z/2\) surgical formula;
- theorem-level general finite \(A\) \(\Omega_a\) formula;
- decorated Kirby-move / presentation invariance gate;
- any closed invariant or exotic-pair computation claim.
