This note pins what the first colored framed link evaluator must know before it is used by any
Kirby-color or 4D surgery formula.  It does not implement code and does not certify any closed
4-manifold invariant.

* Boundary: Link Evaluator Versus 4D Surgery Normalization

The first evaluator should compute ordinary colored framed link values in a fixed RT or
Kauffman-bracket convention.  Its output is a link-evaluation building block.

It must not silently include:

- Kirby color sums such as \(\omega=\sum_i d_i X_i\) or decorated variants such as
  \(\Omega_a=\sum_i d_i\lambda_i(a)X_i\);
- 4D handle-count normalization;
- signature / anomaly corrections;
- Broda, Crane-Yetter, or Yetter closed-manifold normalization;
- 1-/3-handle or dotted-circle conventions.

Those belong to later ordinary/twisted surgery nodes.  Using them inside the link evaluator would
make it hard to audit whether a discrepancy comes from RT link conventions or from 4D
normalization.

** Colored unknot value

The first evaluator must decide the value of a 0-framed unknot colored by a simple object \(i\).

- =WORKING TARGET=: \(\langle U_0(i)\rangle=d_i\), the quantum dimension of \(i\).
- =SOURCE NEEDED=: page / definition / proposition source for this normalization in the selected
  RT or Kauffman-bracket reference.
- =SOURCE NEEDED=: whether the source writes this as \(d_i\), \(\Delta_i\), bracket-theoretic
  \((-1)^i[n]\), or another convention.
- =WARNING=: until the source is pinned, do not identify \(\Delta_i\) from Yetter's
  \(\omega,\theta\) notation with \(d_i\) at theorem level.

** Framed unknot twist

The evaluator must decide how integer framing changes the colored unknot value.

- =WORKING TARGET=: \(\langle U_f(i)\rangle=\theta_i^f d_i\), where \(\theta_i\) is the ribbon
  twist eigenvalue of simple object \(i\).
- =SOURCE NEEDED=: sign convention for positive framing / right-handed full twist.
- =SOURCE NEEDED=: exact \(\theta_i\) values for =SU(2)_2= in the selected convention.
- =SOURCE NEEDED=: whether the Kauffman-bracket convention uses \(A^{i(i+2)}\),
  \((-1)^i A^{i(i+2)}\), its inverse, or another twist factor.

** Unlink multiplicativity

The evaluator must decide how disjoint union is normalized.

- =WORKING TARGET=: the colored value of a split unlink is multiplicative:
  \[
  \langle L\sqcup U_0(i)\rangle=\langle L\rangle d_i.
  \]
- =SOURCE NEEDED=: source label for multiplicativity / monoidal normalization.
- =SOURCE NEEDED=: whether there is an overall empty-link normalization distinct from \(1\).
- =WARNING=: this is an RT link-evaluation convention, not the Kirby-color multiplicativity after
  summing over labels.

** Hopf link / S-matrix values

The evaluator needs a known nontrivial two-component control, preferably the Hopf link.

- =WORKING TARGET=: for a positively oriented, 0-framed Hopf link colored \(i,j\), use a convention
  compatible with the modular \(S\)-matrix, such as
  \[
  \langle H_+(i,j)\rangle = \frac{S_{ij}}{S_{00}}
  \]
  if the selected RT convention normalizes the 0-framed unknot by \(d_i=S_{0i}/S_{00}\).
- =SOURCE NEEDED=: source page / proposition for the exact Hopf-link-to-\(S\)-matrix formula.
- =SOURCE NEEDED=: orientation convention for \(H_+\) versus \(H_-\), and whether \(S\) or
  \(S^{-1}\) / complex conjugate appears.
- =SOURCE NEEDED=: exact =SU(2)_2= \(S\)-matrix in the same root-of-unity convention.

** Kauffman bracket expected controls

If the first evaluator is bracket-first rather than abstract RT-first, it must instead pin
bracket controls.

- =WORKING TARGET=: record the bracket value of a colored 0-framed unknot, framed twist, split
  unlink, and Hopf link in one consistent \(A\)-convention.
- =SOURCE NEEDED=: Jones-Wenzl idempotent normalization for the colored unknot.
- =SOURCE NEEDED=: Kauffman bracket skein relation, loop value, and root-of-unity specialization.
- =SOURCE NEEDED=: conversion between bracket labels and =SU(2)_k= simple-object labels.
- =WARNING=: do not mix bracket \(A\)-powers with RT twist/S-matrix values unless the conversion is
  explicitly recorded.

Before =n18-colored-framed-link-evaluator-gate= treats output as convention-pinned, the repo needs:

- integer framed unknot twist factor with sign convention and source label;

- exact =SU(2)_2= dimensions, twists, and \(S\)-matrix in one convention;
- explicit statement that no Kirby color, surgery normalization, or 4D invariant normalization is
