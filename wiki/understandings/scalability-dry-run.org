本節點是 repo-local pipeline 的 scalability / readiness ledger。它只對目前
已存在的 toy metadata、candidate metadata、gate status 做 deterministic counting
與 blocker 整理。它不是 real exotic input 的 performance benchmark，也不是
twisted Yetter exotic computation。

因為 =n70-exotic-input-certification= 目前是 =data-blocked=，=n75= 的正確
狀態也是 =dry-run-blocked=。這個狀態明確表示：目前不能進入
=n80-exotic-computation=，也不能宣稱已能計算 exotic pair。
