* Exact v0 Input Type

The invariant core input type for v0 is exactly the following tuple:

#+begin_src text
(
  category_certificate,
  kirby_matrix_presentation,
  decoration_mod2,
  formula_convention_record,
  claim_level
)
#+end_src

with these restrictions:

- =category_certificate= must be the current =SU(2)_2= category-data certificate
  represented by =src/twisted_yetter/su2_level2.py=:
  - simple labels =("0", "1", "2")=;
  - exact quantum dimensions in =Q(sqrt(2))=;
  - fusion rules and global dimension check only;
  - no assumed twists, braiding, =F=-symbols, =R=-symbols, or numeric
    =omega/theta= coefficients beyond what is explicitly recorded.
- =kirby_matrix_presentation= must be a
  =twisted_yetter.linking_matrix.KirbyMatrixPresentation=:
  - symmetric integer linking/intersection matrix =Q=;
  - component IDs and orientation labels of the same length as =Q=;
  - no dotted 1-handle data;
  - no link diagram, crossing, or full Kirby calculus data;
  - intended only for the small no-1-handle toy examples already supported by
    the matrix model.
- =decoration_mod2= must be one vector in =(Z/2)^n= in the current 2-handle
  basis, where =n= is the matrix size.
  - The all-zero vector is denoted =alpha=0=.
  - Under a recorded =GL(n,Z)= basis change with columns equal to new basis
    vectors in old coordinates, the decoration transforms by
    =x_new = P^{-1} x_old mod 2=, following
    =wiki/understandings/kirby-matrix-model.org=.
- =formula_convention_record= must point back to this note and to
  =wiki/understandings/formula-conventions.org=.
- =claim_level= must be one of:
  - =experimental-matrix-statistic=;
  - =ordinary-control-input=;
  - =presentation-gate-input=.

No other category, coefficient group, handlebody type, or closed-manifold
claim is part of v0.

* Alpha Equals Zero Expected Behavior

The expected v0 behavior for =alpha=0= is:

- =alpha=0= uses the ordinary / undecorated input path of the experimental
  formula.
- In the color language of the convention ledger, =alpha=0= corresponds to the
  =omega= sector rather than the nontrivial =theta= sector.
- The output is expected to match the same implementation's ordinary-control
  path on the same presentation, with the same experimental normalization and
  signature-correction names.
- The all-zero decoration must be stable under recorded basis change.
- The actual ordinary invariant values are not accepted at n30; they are
  tested later by =n40-ordinary-control-gate=.

An =alpha=0= mismatch in n40 is a gate failure and should route through the
decision graph's failure triage, not be patched by changing this contract
silently.
