This note is the central confidence ledger for early twisted Yetter work.  It decides which
statements may be used as schema / test scaffolding and which statements may support a mathematical
claim.

It intentionally does not change the CTL decision graph, does not source-audit external literature,
and does not promote any provisional formula to theorem status.

* Confidence Classes

Use these labels consistently in later notes and artifacts.

| Class | Meaning | May support |
|-------+---------+-------------|
| =SOURCE NEEDED= | Expected or remembered statement, but no page / theorem / definition source has been captured. | Checklists, TODOs, failure triage only. |
| =audited-working= | Source record exists with locator and exact labels, but the repo has not yet connected it to every downstream convention. | Local convention choice and source-aware tests. |
| =provisional= | Internally coherent working assumption with clear missing source or proof obligations. | Experimental computations, not theorem-level claims. |
| =provisional-low-confidence= | Especially fragile provisional claim; current repo treats it as a hypothesis to audit. | Schema names, negative/positive debug signals, source-audit targets only. |
| =candidate-experimental= | Formula or construction proposed for experiments and falsification. | Candidate validation suites only. |
| =sanity-check-only= | Artifact checks input consistency but is not the mathematical object being computed. | Input QA and certificate metadata only. |
| =schema/test-safe= | Safe to encode in JSON schemas, unit tests, fixtures, and gates as a local convention. | Software correctness under stated local assumptions. |
| =claim-supporting= | Source-audited or proved in repo at the level needed for the claim. | Mathematical claims within its stated hypotheses. |

Current n05 result: no entry below is =claim-supporting= for a closed homologically twisted
Crane-Yetter / Yetter invariant.  The usable status is mainly =schema/test-safe= or weaker.

* General Finite =A= \(\Omega_a\) Candidate

** Confidence

- ledger class: =candidate-experimental=.
- audited status: =NOT PROVED IN REPO= and =SOURCE NEEDED= if claimed from literature.

** Candidate

The current candidate expression is
\[
\Omega_a=\sum_{i\in\operatorname{Irr}(\mathcal C)} d_i\,\lambda_i(a)\,X_i,
\qquad
a\in A=\operatorname{Aut}_{\otimes}(\operatorname{Id}_{\mathcal C}).
\]

Here \(a_{X_i}=\lambda_i(a)\operatorname{id}_{X_i}\) is the expected scalar action on simple
objects.  This scalar-action statement itself needs exact source labels before theorem-level use in
the Yetter formula context.

** Allowed use

- =schema/test-safe=: implement finite abelian groups, character tables, and exact coefficient
  storage.
- =candidate-experimental=: run validation suites that compare candidate behavior across many
  examples.
- =candidate-experimental=: use failures as evidence that the candidate or convention is wrong.

** Forbidden use

- Do not describe \(\Omega_a\) as the general homologically twisted Kirby color.
- Do not use the candidate to support mathematical invariance, exotic detection, or no-go claims.
- Do not let passing examples promote the formula beyond =candidate-experimental=.

* Matrix and Intersection-Form Artifacts

** Confidence

- ledger class: =sanity-check-only= / =schema/test-safe=.
- audited status: local software convention, not a topological calculator.
- related notes:
  - =wiki/understandings/kirby-matrix-model.org=
  - =wiki/understandings/formula-contract-v0.org=

** What they can check

Matrix/intersection-form artifacts may record and test:

- symmetry, size, rank, determinant, nullity, parity, and exact signature triple;
- component IDs and local basis labels;
- basis-change matrices and local coordinate transformations;
- all-zero decoration consistency;
- Euler characteristic / handle-count sanity data when explicitly supplied.

** What they cannot check

They cannot replace:

- machine-readable Kirby/link diagram input;
- colored framed link evaluation;
- Kirby-color summation;
- 4D surgery normalization;
- decorated handle-slide proof;
- closed-manifold invariant certification;
- exotic-pair marking certification.

** Allowed use

- =schema/test-safe=: use matrix data as input QA, fixture metadata, and regression tests.
- =sanity-check-only=: compare signatures, ranks, determinants, and basis-change behavior.

** Forbidden use

- Do not call matrix/intersection-form outputs a twisted Yetter calculator.
- Do not infer smooth-structure sensitivity from matrix-level differences.
- Do not satisfy =n18=, =n24=, =n35=, =n50=, or exotic computation gates using only matrix
  statistics.
