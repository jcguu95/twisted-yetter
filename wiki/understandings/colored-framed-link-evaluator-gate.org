本 node 現在是 =n18b= restricted core 的 gate，不是舊式 fixture-only expected-value gate。
它要求 empty link、split unlink、framed unknot、positive Hopf controls 都經過同一個
=evaluate_su2_level2_link(LinkDiagram, labels_by_component)= 入口，並要求 general crossings /
dotted Kirby components 產生 structured blocker。

它不是 general planar RT evaluator，不是 Kirby color，不是 4D Kirby formula，不是 twisted
Yetter formula，也不是 exotic computation。通過此 gate 只表示目前已有一個 restricted bare
=SU(2)_2= colored framed link evaluator core，可作為下一層 ordinary Kirby-color source/implementation
工作的輸入邊界。

* Structured Blockers

Gate 只接受 manifest 中 elementary controls 與 positive Hopf controls。它另有兩個 default
blocker checks：

- general crossing diagram: =reason_id: general-crossing-diagram-unsupported=。
- dotted component: =reason_id: dotted-components-unsupported=。

這是刻意的：n18 gate 不能 silently pass unsupported general diagrams，也不能把 Hopf-specific
control 誤標成 general crossing evaluator。若 caller 將 unsupported diagram 放進 supported
control path，gate 會因 core blocker raise =NotImplementedError=。
