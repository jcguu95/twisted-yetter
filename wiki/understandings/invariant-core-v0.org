* Implemented Scope

=src/twisted_yetter/invariant.py= implements the minimal deterministic core
allowed by n30:

- formal =omega/theta= sector records for one =Z/2= decoration vector;
- deterministic decoration aggregation in lexicographic =mod 2= order;
- exact JSON-compatible matrix sanity data: size, rank, determinant, parity,
  signature triple, and =alpha^T Q alpha mod 2=;
- exact canonical comparison of official JSON-compatible outputs;
- artifact-v1 certificate wrapping with status =inconclusive=;
- explicit unsupported errors for non-v0 claim levels, non-current category
  certificates, altered formula-convention records, and numerical invariant
  evaluation.

The normalization and signature correction are recorded only by name:

- =experimental-yetter-surgery-normalization-v0=
- =experimental-signature-correction-v0=

* Unsupported / Inconclusive Items

Numerical invariant values remain unsupported because n30 leaves the following
items =SOURCE NEEDED=:

- exact =omega/theta= coefficients;
- whether =Delta_i= equals quantum dimension in the source convention;
- parity convention;
- closed twisted invariant normalization;
- signature phase / anomaly convention;
- Kirby move proof and treatment of 1-/3-handles.

Therefore sector records have =value_status: inconclusive=.  This is deliberate
contract behavior, not a computation failure.
