* Gate Policy

n50 compares equivalent presentations only after applying the recorded
decoration transform

#+begin_src text
x_new = P^{-1} x_old mod 2
#+end_src

where the columns of =P= are the target basis vectors written in the source
basis.

The gate deliberately does not compare raw full n35 JSON outputs.  Raw outputs
contain basis-dependent data such as:

- =presentation.matrix=;
- =presentation.component_ids=;
- =presentation.framings=;
- coordinate =decoration_mod2=;
- =sector_id=;
- =aggregation.sector_order=;
- =component_colors=;
- =theta_component_count=.

These fields can change under a recorded basis change even when the formal
matrix-level invariant data being gated is stable.

The n50 projection compares only exact fields expected to be stable under the
recorded congruence and decoration transform:

- status, claim level, claim boundary;
- category and formula convention metadata;
- =ordinary_path_selected=;
- aggregation mode / =value_status= / unsupported reason, excluding
  coordinate-based =sector_order=;
- presentation size, rank, determinant, signature triple, signature, parity;
- formal =alpha^T Q alpha mod 2= and sector =value_status=.

* Computed Evidence

The tests in =tests/test_presentation_invariance_gate.py= check all built-in
n45 fixtures:

- =hyperbolic-shear= for the =S2xS2= hyperbolic form;
- =odd-indefinite-swap= for =CP2#anti-CP2=;
- =odd-positive-shear= for =CP2#CP2=.

For each fixture, every recorded nonzero source decoration is transformed by
the fixture's =decoration_transform_mod2= and the projected n35 outputs agree
exactly.  The all-zero decoration remains all-zero and keeps
=ordinary_path_selected: true= for every fixture.

The gate artifact records verdict =pass= and route
=allow-n55-toy-closed-suite=.

* Failure Classification

The gate includes a minimal non-failing-but-important example:

#+begin_src text
source matrix: [[0, 1], [1, 0]]
target matrix: [[0, 1], [1, 2]]
source alpha:  [0, 1]
target alpha:  [1, 1]
classification: raw-presentation-payload-mismatch
#+end_src

Here raw full n35 outputs differ because matrix and component metadata differ.
The projected outputs agree.  Therefore this is not an n50 failure; it records
why comparing raw full artifacts would be the wrong gate.

An actual n50 failure should include the minimal source/target matrices,
source/target decorations, basis matrix, and the first projected field that
differs.  That route should go to n60 or another implementation/theory triage
node rather than patching =src/= silently.

* Trust Boundary

This pass says only:

- the current n35 formal matrix outputs are stable under the n45 recorded basis
  changes after applying the recorded mod-2 decoration transform;
- =alpha=0= remains stable for the same fixtures;
- raw metadata differences are classified rather than mistaken for invariant
  failures.

It does not say:

- the numerical twisted Yetter invariant is defined;
- the closed 4-manifold normalization is source-audited;
- handle-slide / Kirby invariance is proved in the literature;
- 1-/3-handle behavior is covered;
- exotic smooth structure detection is supported.
