* Required Artifacts Before n70

n70 input certification needs at least:

1. source reference records with canonical metadata, locator, capture time, and
   content hash or git blob hash;
2. exact page, figure, theorem, or proposition ids for every selected input
   claim;
3. machine-readable Kirby or handle data for both sides of one selected exotic
   pair;
4. component ids, framings, dotted status, orientation, and lineage for both
   sides;
5. integer linking matrices and topological sanity checks for both sides;
6. \(H_2\) / homeomorphism comparison or marking certificate with basis-change
   matrices;
7. upstream pass certificates for =n24=, =n50=, and =n55= before any closed
   exotic computation claim.

* Blockers

The artifact records these stable blocker ids:

- =source-needed-for-candidate-claims=
- =missing-machine-readable-exotic-kirby-diagrams=
- =missing-h2-homeomorphism-marking-certificate=
- =n24-n50-n55-upstream-blocked=

The last blocker matters even if a candidate source route looks promising:
=n24-ordinary-surgery-gate= is still =blocked=, =n50-decorated-kirby-move-gate=
is still =blocked=, and =n55-toy-closed-suite= is still =blocked=.  Therefore
candidate scouting cannot be promoted into closed twisted Yetter values or any
exotic smooth-structure comparison.

* Claims Explicitly Refused

n65 explicitly refuses:

- certified exotic input claim;
- =n70= exotic input certification pass;
- =n80= exotic computation route;
- exotic smooth-structure detection claim;
- marked distinction claim;
- cork-canonical distinction claim;
- unmarked total-function distinction claim;
- closed 4-manifold invariant claim.

The code also has claim-promoter flags that raise =ValueError= if a caller tries
to use the scout ledger as certification or computation.
