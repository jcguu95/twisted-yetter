This node intentionally does not pass the ordinary surgery gate.  Its output is a deterministic
=blocked= certificate so later CTL nodes do not accidentally treat n22/n23 scaffolds as a closed
ordinary 4D invariant.

* Executable Contract

=ordinary_surgery_gate_certificate()= returns schema:

#+begin_src text
twisted-yetter.ordinary-surgery-gate.v1
#+end_src

The certificate records:

- =status= as =blocked=;
- =ordinary_surgery_claim_allowed=false=;
- =closed_4_manifold_claim_allowed=false=;
- =claim_supporting_closed_invariant_allowed=false=;
- every n21 source slot inherited from =ordinary_kirby_color.SOURCE_STATUS_BY_SLOT=;
- deterministic =blocked_reasons= for n21, n22, n23, and closed-claim refusal.

Calling:

#+begin_src python
ordinary_surgery_gate_certificate(claim_supporting_closed_invariant=True)
#+end_src

raises a refusal instead of producing a misleading certificate.

* Blocked Reasons

** n21 source slots

All ordinary Kirby-color / surgery source slots remain =SOURCE NEEDED=:

- =kirby_color_coefficients=
- =global_dimension_and_normalization=
- =signature_anomaly_framing_convention=
- =handle_slide_invariance_proof_scope=
- =one_two_cancellation_treatment=
- =two_three_cancellation_treatment=
- =closed_4_manifold_vs_2_handlebody_distinction=

Therefore the gate cannot support a theorem-level ordinary closed 4-manifold invariant.

** n22 local convention only

n22 is still =experimental/local-convention= with handle scope:

#+begin_src text
no-dotted-2-handle-framed-link-only
#+end_src

Its normalization status is =SOURCE NEEDED=.  It is useful as exact regression scaffold evidence,
not as a sourced surgery formula.

** n23 S2xS2 crossing control blocked

n23 records =S2xS2-hopf= as =blocked=.  The Hopf fixture has two crossings and linking matrix:

#+begin_src text
[[0, 1], [1, 0]]
#+end_src

The current n22 ordinary Kirby-color scaffold refuses crossing/Hopf diagrams, so the first known
ordinary 4D control requiring a crossing-capable ordinary layer is not available.

** Closed claim refusal

n24 refuses =claim_supporting_closed_invariant=True=.  This is deliberate: a blocked gate should
not be a host exception in normal status queries, but it must not silently authorize closed
ordinary invariant claims either.

* Downstream Effect

This node unblocks only:

- =n30-provisional-formula-policy= as a consumer of an explicit ordinary-surgery blocker.

It does not unblock:

- claim-supporting ordinary closed 4D invariant values;
- decorated formula claims;
- twisted formula claims;
- exotic smooth-structure detection claims.
