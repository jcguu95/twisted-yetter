This gate is a scaffold for decorated Kirby move / presentation checks.  It
does not prove a decorated Kirby theorem.  Its current job is to make the data
flow machine-checkable: the built-in toy presentation pairs from n45 are
candidate/dry-run metadata and must remain blocked until they carry explicit
certificates.

* Artifact Schema

The schema id is:

#+begin_src text
twisted-yetter.decorated-kirby-gate.v1
#+end_src

The default artifact is produced by:

#+begin_src python
from twisted_yetter.decorated_kirby_gate import decorated_kirby_gate_artifact

artifact = decorated_kirby_gate_artifact()
#+end_src

The artifact records:

- =status= =blocked=;
- =node_id= =n50-decorated-kirby-move-gate=;
- the consumed n45 registry schema/status/node id;
- n45 registry metadata validation;
- inherited =ordinary_surgery_gate_status=;
- one =pair_classifications= entry per n45 pair;
- =final_decorated_gate_passed: false=;
- explicit claim blockers for presentation equivalence theorem, decorated
  Kirby move theorem, closed 4-manifold invariant claim, and exotic detection
  claim;
- =required_unblock_artifacts= listing what a future node must provide.

The JSON serializer =stable_decorated_kirby_gate_json= uses sorted keys and the
tests require deterministic output with no float marker such as =.0=.

* Current Pair Classification

Every built-in n45 pair is currently classified as:

#+begin_src text
blocked
#+end_src

The structured blocker reason ids are:

- =presentation-pair-candidate-dry-run=: n45 relation status is not a certified
  decorated Kirby move.
- =missing-decorated-move-certificate=: no machine-checkable handle-slide,
  stabilization, cancellation, or component-order certificate is recorded.
- =missing-component-lineage-certificate=: component lineage is prose /
  placeholder metadata, not a certified move lineage.
- =missing-basis-matrix-certificate=: =basis_map.claim_certified= is false or
  the integer matrix is absent.
- =ordinary-surgery-gate-blocked=: n24 is still blocked, so closed 4D claims
  are not supported.
- =missing-source-proof=: no source-audited theorem/proposition or repo-local
  proof artifact is attached.

This is intentional.  The gate turns a vague "not ready" state into a stable
machine-readable blocked certificate.

* Trust Boundary

Passing the n50 scaffold tests means:

- the n45 registry can be consumed deterministically;
- each current toy pair receives structured blocker ids;
- high claims are refused both by artifact booleans and by API claim flags;
- downstream nodes can inspect stable JSON instead of scraping prose;
- no floating-point data appears in the gate artifact.

Passing these tests does not mean:

- presentation equivalence is proved;
- decorated Kirby move invariance is proved;
- a closed 4-manifold invariant has been constructed;
- the candidate =Omega_a= formula has theorem-level status;
- exotic smooth-structure detection is supported.

* Required Future Artifacts

To unblock this gate, a future node needs at least:

- decorated Kirby move certificates for accepted presentation pairs;
- certified component lineage with component ids before/after every move;
- integer basis matrices, including the induced =H_2= label transformation;
- ordinary surgery gate support sufficient for closed 4D claims;
- source-audited proof records for the decorated move rule being used;
- failure minimization records if a handle-slide, basis-change, or ordinary
  regression mismatch appears.

Until those are present, n55 toy closed computations and any exotic route must
treat n50 as blocked.
