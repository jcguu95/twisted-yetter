This gate is a classifier for decorated Kirby move / presentation checks.  It
does not prove a decorated Kirby theorem.  Its current job is to make the data
flow machine-checkable: the built-in toy presentation pairs from n45 are
candidate/dry-run metadata and must remain blocked until they carry explicit
generated link-diagram certificates; n45 matrix pairs are preserved only as
=metadata-only= matrix-level sanity checks.

* Trust Boundary

Passing the n50 scaffold tests means:

- the n45 registry can be consumed deterministically;
- each current toy or matrix pair receives a structured classification;
- each current diagram toy pair receives structured blocker ids;
- matrix-level consistency is retained as =metadata-only= and not promoted;
- evaluator comparison input ids are explicit and currently empty;
- high claims are refused both by artifact booleans and by API claim flags;
- downstream nodes can inspect stable JSON instead of scraping prose;
- no floating-point data appears in the gate artifact.

Passing these tests does not mean:

- presentation equivalence is proved;
- decorated Kirby move invariance is proved;
- matrix-level =GL(n,Z)= consistency is a link-diagram Kirby move proof;
- a closed 4-manifold invariant has been constructed;
- the candidate =Omega_a= formula has theorem-level status;
- exotic smooth-structure detection is supported.

* Required Future Artifacts

To unblock this gate, a future node needs at least:

- generated link-diagram decorated Kirby move certificates for accepted
  presentation pairs;
- certified component lineage with component ids before/after every move;
- integer basis matrices, including the induced =H_2= label transformation;
- ordinary surgery gate support sufficient for closed 4D claims;
- n35 decorated-core calls upgraded from planned metadata to executed
  evaluator-backed calls;
- source-audited proof records for the decorated move rule being used;
- failure minimization records if a handle-slide, basis-change, or ordinary
  regression mismatch appears.

Until those are present, n55 toy closed computations and any exotic route must
treat n50 as blocked.
