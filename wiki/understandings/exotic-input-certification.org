* Certification Criteria

To route from candidate selection into exotic-pair computation, one selected
pair must have all of the following repo-local artifacts.

1. Source reference records with canonical metadata, locator, capture time, and
   content hash or git blob hash.
2. Exact page, theorem, proposition, or figure references for every diagram,
   handle move, cork twist, and no-1/no-3-handle claim used.
3. Machine-readable Kirby or handle data for both sides: component ids,
   framings, dotted status, orientation, PD code or braid/link representation,
   and component lineage.
4. Integer linking matrix or equivalent presentation data sufficient to
   recompute rank, determinant, parity, signature, Euler characteristic, and
   expected intersection form.
5. Explicit =H_2= identification or comparison certificate: marked,
   cork-canonical, orbit, multiset, or explicitly inconclusive.
6. Basis-change matrices from source/cork basis to final diagram basis, when
   the final diagram is not already the comparison basis.
7. Sanity-check log showing that ordinary structural checks pass and that
   =alpha=0= is routed through the ordinary-control path.

Without these items, any exotic calculation would depend on ad hoc human
interpretation of diagrams or unstated marking choices.
