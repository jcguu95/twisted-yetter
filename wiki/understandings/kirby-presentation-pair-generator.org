This node builds deterministic Kirby/link presentation-pair metadata for later
decorated Kirby move gates.  It now has two explicitly separated trust levels:

- diagram/decorated-core pairs: candidate/dry-run registry metadata only;
- matrix-level pairs: machine-checkable =GL(n,Z)= basis-change fixtures for
  recorded intersection forms only.

It is not a link-diagram Kirby move proof, not a decorated Kirby move theorem,
not link evaluation, not a Kirby color sum, not a closed invariant, and not
exotic-pair evidence.

The registry records:

Each pair records at least:

- =pair_id=;
- =pair_kind=;
- =left= and =right= side summaries with fixture path, diagram id, component ids,
  finite group, decoration summary, and candidate sector ids;
- =relation_type=;
- =relation_status= =candidate/dry-run=;
- =component_lineage= with placeholder status;
- =move_metadata= with operation class and dry-run notes;
- =basis_map= with placeholder status and =claim_certified: false=;
- =decorated_core_case_refs= and embedded =decorated_core_cases= summaries from n36;
- =claim_level=, =claim_boundary=, =source_status=, and =does_not_prove=.

Matrix-level pairs record:

- =source= and =target= matrix presentations;
- exact =basis_map.matrix= and =basis_map.inverse_matrix=;
- =decoration_transform_mod2=;
- transformed decoration vectors;
- component lineage between recorded source/target basis labels;
- =machine_checked_matrix_equivalence: true=.

This machine-checks only the matrix presentation relation.  It does not certify
that a machine-readable link diagram was transformed by a Kirby handle slide.

* Trust Boundary

Passing the registry tests means:

- n50 can see required pair fields in deterministic JSON;
- toy identity, zero-decoration, nonzero \(Z/2\), and component-order dry-run
  shapes are represented;
- the Hopf mixed-label relabel dry-run shape is represented;
- matrix-level handle-slide/swap/shear fixtures are present with exact
  =GL(n,Z)= basis and inverse matrices;
- associated decorated-core case summaries come from n36 metadata;
- JSON serialization is stable;
- serialized JSON contains no float marker such as =.0=.

Passing the registry tests does not prove:

- presentation equivalence;
- Kirby move correctness;
- decorated Kirby move invariance;
- link-diagram basis-change correctness;
- link evaluation correctness;
- closed 4-manifold invariant status;
- exotic smooth-structure distinction.
