not a coefficient implementation, and not a closed 4-manifold invariant calculator.

without silently upgrading the general finite \(A\) candidate formula into a sourced Yetter
formula.

\[
\Omega_a=\sum_i d_i\lambda_i(a)X_i.

- =claim_level=: =candidate-experimental= or =schema-test-safe= only.

* Character Table Requirement

Artifacts must identify the finite group and the exact character table source.  Current =n11=
support is intentionally tiny: trivial group and \(Z/2\), through
=src/twisted_yetter/finite_groups.py=.

Required properties for =n33=:

- exact character values;
- exact row and column orthogonality;
- no floating-point character data;
- deterministic labels for group elements and characters;
- explicit =finite_group_id= and =character_table_source= fields.

This is a schema and exactness requirement.  It does not prove the candidate formula.

* Specialization Checks

Future candidate artifacts and tests should include these checks before any result is treated as
meaningful candidate evidence:

- =trivial-a-recovers-ordinary-omega-candidate=: for trivial \(A\), the only sector should
  specialize to the ordinary \(\omega\) candidate while still carrying ordinary-surgery gate
  metadata.
- =z2-nontrivial-sector-aligns-with-theta-target-if-sourced=: for \(A=Z/2\), the nontrivial
  sector should align with the \(\theta\) target only if =n31= later confirms the source and
  convention slots.
- =character-orthogonality-and-exactness=: finite-\(A\) character data must pass exact
  orthogonality and must not use floats.
- =zero-and-all-trivial-decorations=: zero / all-trivial decorations must route to the ordinary
  candidate sector, not to an unstated decorated formula.

Passing these checks is computed evidence for the candidate only.  It is not proof of decorated
Kirby invariance.

* Falsification Criteria

The candidate should be treated as falsified or routed to source/convention/code triage if any of
the following occur:

- =toy-examples-inconsistent=: exact toy examples contradict the stated specialization checks or
  accepted local controls.
- =z2-mismatch-after-source-capture=: after =n31= fills the \(Z/2\) source slots, the nontrivial
  sector disagrees with the sourced \(\theta\) formula.
- =handle-slide-or-presentation-mismatch=: the candidate gives incompatible values for
  presentations later certified equivalent by decorated Kirby-move gates.
- =exact-arithmetic-inconsistency=: the same input yields nonidentical exact certificates, uses
  floating approximations, or fails exact character orthogonality.

Falsification here means the candidate contract has found a real problem to investigate.  It does
not by itself prove a no-go theorem.
